# Windows packaging

## Current artifact

The Windows CI produces `Tokeni-Bar-Windows-<version>.zip`. Extract the archive and
run `TokeniWindows.exe`; the package is portable and does not need a machine-wide
installation. The archive includes the executable, native DLLs, Swift runtime DLLs,
and SwiftPM resource bundles emitted by the release build.

현재 Windows CI는 `Tokeni-Bar-Windows-<version>.zip`을 생성합니다. 압축을 푼 뒤
`TokeniWindows.exe`를 실행하면 되며, 시스템 전체 설치가 필요 없는 portable
패키지입니다. release 빌드에서 나온 실행 파일·native DLL·SwiftPM resource bundle을
함께 포함합니다.

## Scope and limitations

This is an unsigned validation artifact. Windows SmartScreen or endpoint policy may
warn before first launch. MSIX/MSI signing, Start Menu registration, uninstall, and
automatic update installation are intentionally not enabled yet; those require a
signed distribution contract and will be connected in the final integration work.

이는 서명하지 않은 검증용 artifact입니다. 첫 실행 때 Windows SmartScreen 또는
보안 정책이 경고할 수 있습니다. MSIX/MSI 서명, 시작 메뉴 등록, 제거 프로그램과
자동 업데이트 설치는 아직 활성화하지 않았으며, 서명된 배포 계약을 확정한 뒤 최종
통합 단계에서 연결합니다.

The package is generated by `Scripts/package_windows.ps1`. It accepts a release
directory from `swift build --show-bin-path` plus Swift runtime library directories,
validates the semantic version, refuses unsafe output roots, and only removes its own
staging directory and archive.

패키지는 `Scripts/package_windows.ps1`이 생성합니다. `swift build --show-bin-path`의
release 디렉터리와 Swift runtime library 디렉터리를 입력으로 받고 semantic version을
검증하며, 위험한 출력 루트를 거부하고 자신이 만든 staging 디렉터리와 archive만
삭제합니다.

## CI 범위

Windows 전용 pull request는 Windows build·package 검증만 실행하고, SwiftPM build
cache를 재사용합니다. 전체 macOS CI는 공통 코드나 macOS 코드가 변경될 때만
실행됩니다. Windows workflow를 `workflow_dispatch`로 직접 실행하면 Windows 전용
업데이트 설치·tray 상세 화면 테스트도 함께 실행됩니다.

Windows-only pull requests run the Windows build and packaging validation and reuse the
SwiftPM build cache. The full macOS CI runs only when shared or macOS code changes.
Dispatching the Windows workflow manually also runs focused Windows update-installer and
tray-detail tests.
