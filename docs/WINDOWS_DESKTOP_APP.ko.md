# Windows 데스크톱 앱

Windows 앱은 Win32 기본 컨트롤과 기존 Swift 공통 상태를 연결합니다.
수동 실행은 메인 창을 열고, `--background` 실행은 트레이에서 시작합니다.
자동 시작을 새로 설정하면 백그라운드 실행 인자가 함께 등록됩니다.

## 화면과 동작

- 홈: 연결된 제공자 수, 갱신 상태, 제공자별 사용량 표.
- 사용량: 제공자별 상태·잔여량·초기화·토큰·비용 표와 쿼터별 상세 정보.
- 펫: 보유 펫 선택, 성장 대상 저장, 보유한 알 부화, 데스크톱 캐릭터 표시.
- 설정: 제공자 활성화, 자동 시작, 알림 테스트, 캐릭터 표시, 앱 종료.

트레이 아이콘으로 창을 다시 열 수 있습니다. 창 닫기와 Escape는 트레이로 숨기며,
설정 또는 트레이의 종료 명령은 앱을 종료합니다. 창을 다시 실행하면 기존 인스턴스를
활성화합니다. 일반 창 위치는 사용자별로 저장하고, 모니터 구성이 바뀌면 화면 안으로
보정합니다. 표는 키보드로 탐색하고 가로·세로 스크롤할 수 있습니다.

값이 오래되었거나 연결에 실패하면 현재 수치로 표시하지 않습니다. 펫 성장과 저장은
기존 엔진을 사용하며 UI에서 성장량을 계산하지 않습니다. 설정·부화·성장 대상 변경
결과는 화면에 표시하며 저장 실패 시 이전 펫 상태를 유지합니다.

## 구현 경계

- `TokeniApplication`: 제공자 중립적인 사용량 상태.
- `WindowsDashboardPresentation`: 상태를 Windows 표에 표시할 값으로 변환.
- `WindowsTrayShell`: Swift와 C 사이의 UI 데이터 전달 및 사용자 요청 수집.
- `WindowsTrayNative.c`: 전용 메시지 스레드, 트레이, 메인 창, 기본 컨트롤.
- `WindowsCompanionGrowthCoordinator`: 기존 엔진을 통한 펫 변경과 저장.

스냅샷은 완성한 뒤 UI에 전달합니다. UI는 파일이나 제공자 인증 정보를 직접 읽지
않습니다. 오버레이 창도 메시지 루프가 있는 UI 스레드에서 생성합니다.

## 검증

`swift test`와 `swift build`는 Windows 도구 체인 및 macOS CI에서 검증합니다.
`Windows desktop controls` 워크플로는 별도 네임스페이스의 실제 Win32 창으로 화면
전환·사용자 요청·숨기기·재열기·종료를 검증합니다. 이 테스트는 사용자 설정과
사용량 데이터를 읽거나 변경하지 않습니다.

현재 데스크톱 화면은 영어를 사용합니다. macOS의 모든 기록 차트·펫 상점·화면 설정과
동일한 기능을 제공하지는 않습니다. 다크 모드 전용 디자인, 전체 한영 UI 번역과
설치 프로그램은 후속 작업입니다. 현재 단계의 배포 형식은 portable ZIP입니다.
