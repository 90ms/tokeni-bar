# 제품 목표와 핵심 게임 루프

## 1. 목표

Tokeni Bar를 자주 열어야 하는 별도의 게임으로 만드는 것이 아니라, 에이전트를
사용하는 일상에 작은 성장 보상과 수집 목적을 더한다.

사용자가 느껴야 하는 핵심 감정은 다음 세 가지다.

- 오늘 작업이 눈에 보이는 성장으로 남았다는 만족
- 다음 진화에서 어떤 등급이 나올지 기대하는 긴장감
- 완성한 외형과 희귀한 발견을 도감에 쌓는 수집의 즐거움

## 2. 하지 않을 것

첫 버전에서는 아래 요소를 넣지 않는다.

- 현금 결제, 광고, 재화 구매
- 다른 사용자와 경쟁하는 순위표
- 토큰을 일부러 낭비하게 만드는 일일 미션
- 사용하지 않은 날의 성장 감소, 펫의 죽음 또는 퇴화
- 먹이, 배고픔, 청소처럼 주기적으로 앱을 열도록 강제하는 관리
- 제공자별 전용 펫 또는 특정 플랫폼 우대
- 서버 계정, 클라우드 저장, 소셜 기능
- 여러 종족과 교배, 전투, 장비 경제

이 범위는 메뉴 바 유틸리티의 본래 목적을 해치지 않고 첫 게임 루프의 재미를
검증하기 위한 것이다.

## 3. 핵심 루프

### 매일

1. 사용자가 평소처럼 하나 이상의 에이전트를 사용한다.
2. Tokeni Bar가 신뢰 가능한 토큰 누적값을 관측한다.
3. 오늘의 전체 토큰 사용량을 성장 에너지로 환산한다.
4. 새로 늘어난 에너지만 현재 ByteBot에 반영한다.
5. 메뉴 카드에서 오늘 획득량과 다음 진화까지의 거리를 확인한다.

### 며칠에서 몇 주

1. 성장 에너지가 단계 기준에 도달한다.
2. 진화 결과를 먼저 안전하게 저장한다.
3. 진화 연출과 함께 현재 등급 이상인 새 외형을 공개한다.
4. 새로 발견한 단계·등급 조합이 도감에 등록된다.

### 여러 세대

1. 어덜트까지 키운 ByteBot을 계속 데리고 있거나 여정을 마친다.
2. 여정을 마치면 육성 완료 기록과 최종 등급이 도감에 남는다.
3. 새 알로 다음 세대를 시작한다.
4. 낮은 등급이 이어질수록 천장 수치가 쌓여 장기 좌절을 막는다.
5. 모든 등급·단계 외형과 육성 기록을 채우는 것이 장기 목표가 된다.

## 4. 재미를 만드는 장치

### 예측 가능한 성장

토큰 누적이 커질수록 목표 성장 에너지는 감소하지 않고 상한 없이 다음 구간으로
진행한다. 오늘의 활동이 반영됐는지 사용자가 이해할 수 있어야 한다.

### 예측 불가능한 결과

진화 시점은 예측 가능하지만 등급 상승은 확률적이다. 결과가 저장되기 전에
연출하지 않아 앱을 재실행해 결과를 바꾸는 일을 막는다.

### 손실보다 선택

낮은 등급이 마음에 들지 않으면 새 알을 선택할 수 있다. 그러나 이미 얻은 도감
발견 기록은 유지한다. 조기 재시작은 천장을 올리지 않으므로 반복 리롤의 효율은
낮다.

### 장기적 진척

한 개체가 Normal이어도 실패로 취급하지 않는다. 새로운 단계 외형 발견,
Normal 어덜트 육성 완료 횟수, 천장 진척이 모두 다음 목표로 이어진다.

## 5. 토큰 사용량과 재미의 관계

토큰을 많이 사용하는 사용자는 더 빨리 진화한다. 따라서 같은 기간에 더 많은
세대를 완성하고 희귀 등급을 만날 기회도 많아진다.

등급 확률을 당일 토큰량으로 직접 올리지는 않는다. 그렇게 하면 고사용량 사용자가
속도와 확률을 동시에 얻어 격차가 지나치게 커지고, 진화 직전에 불필요한 요청을
만들 유인이 생기기 때문이다. 속도 차이만으로도 사용량의 보상은 충분히 분명하다.

## 6. 성공 기준

서버 분석 도구를 붙이지 않고 다음의 제품 기준으로 판단한다.

- 토큰 값이 늘었을 때 같은 값이 두 번 성장으로 반영되지 않는다.
- 모든 지원 제공자에서 동일한 성장 규칙을 사용한다.
- 일반적인 사용량에서 첫 부화는 며칠, 어덜트는 약 1~3주 안에 도달한다.
- 결과 화면에서 단계, 등급, 다음 목표를 한눈에 이해할 수 있다.
- 게임을 꺼도 상태 바, 할당량, 비용, 업데이트 기능에 영향이 없다.
- 앱이 강제 종료되어도 펫, 도감, 천장 결과가 서로 어긋나지 않는다.
- 모션 감소, 저전력 모드, 색각 차이에서도 등급과 상태를 구분할 수 있다.

## 7. 향후 후보

첫 버전의 유지율과 제작 비용을 확인한 뒤 다음 순서로 고려한다.

1. 어덜트 친밀도 구간에 따른 외형에 영향을 주지 않는 장식
2. 도감 완성 보상 배지
3. 두 번째 오리지널 펫 계열
4. 로컬 내보내기·가져오기
5. 휴일에도 불이익이 없는 주간 회고 카드

전투, 경쟁, 유료 재화는 현재 제품 방향에 포함하지 않는다.
