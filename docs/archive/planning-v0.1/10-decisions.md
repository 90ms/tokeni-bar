# 사용자 결정 항목

아래 1~6은 구현 전에 결정해야 한다. 각 항목에는 현재 권장안을 먼저 적었다.
7~9는 아트·UI 단계 전까지 정하면 된다.

## 필수 결정

### D1. 성장 곡선과 목표 기간

권장안:

- 일일 하드캡 없음
- `floor(32 × log2(1 + 오늘 토큰 / 25,000))`
- 진화 에너지 80 / 280 / 800
- 일일 5만 토큰이면 약 16일, 10만이면 약 11일, 50만이면 약 6일

결정할 것:

- 이 정도 속도가 적절한가
- 고사용량 사용자가 5~6일에 한 세대를 완성해도 되는가
- 저사용량 사용자의 한 세대가 한 달 이상 걸릴 수 있어도 되는가

### D2. 토큰 데이터가 불완전한 제공자 처리

권장안:

- 토큰이 검증된 제공자만 성장에 포함
- 활동 시간은 행동 애니메이션에만 사용하고 성장 대체값으로 쓰지 않음
- 모든 현재 제공자의 안정 관측 키를 만든 뒤 기본 활성화

대안:

- 토큰을 읽을 수 없는 날에 활동 분당 아주 적은 보정 에너지를 지급

권장안이 플랫폼 간 수치 신뢰는 높지만, 파서가 깨진 사용자는 일시적으로 성장하지
않을 수 있다. 대안은 끊김이 적지만 “토큰 기반 성장”이라는 규칙이 흐려진다.

### D3. 등급 확률과 천장

권장안:

- 최종 기본 분포 Normal 42.2 / Rare 40.9 / Epic 15.5 / Legendary 1.4%
- Rare 이상 3세대, Epic 이상 7세대, Legendary 16세대 안에 보장
- 등급은 하락하지 않음

결정할 것:

- Legendary 1.4%와 최대 16세대가 너무 쉽거나 어려운가
- 정확한 확률과 천장을 UI·문서에 공개할 것인가

권장안은 모두 공개하는 것이다.

### D4. 낮은 등급 중도 이별

권장안:

- 어느 단계에서든 가능
- 현재 에너지와 아직 완료하지 않은 개체는 포기
- 도감 발견과 기존 천장은 유지
- 중도 이별로 천장 진척은 얻지 않음
- 같은 날 이미 받은 에너지 재사용 불가

결정할 것:

- 어덜트 이전에도 항상 허용할지
- 확인 창 외에 24시간 같은 제한이 필요한지

권장안은 별도 시간 제한 없음이다.

### D5. 기존 활동 XP 펫의 이전

권장안 A:

- 기존 펫을 `Legacy ByteBot` 기념 기록으로 보존
- 새 토큰 게임은 Normal 알 0 에너지로 시작

대안 B:

- 기존 단계 진행률을 새 에너지로 비율 변환하고 Normal로 계속 육성

대안 C:

- 기존 단계까지의 등급 판정을 업데이트 순간 실행

사용자 경험과 구현 모두를 고려하면 A가 가장 명확하지만, 기존 펫을 이어 키우고
싶다는 기대와 충돌할 수 있다.

### D6. 어덜트 이후 토큰 처리

권장안:

- 계속 함께 있는 동안 새 에너지를 해당 어덜트의 친밀도로 누적
- 친밀도는 등급과 천장에 영향을 주지 않고 완료 기록에 남음
- 새 알을 받은 뒤 발생한 토큰 증가분부터 새 세대에 지급

대안:

- 친밀도 없이 어덜트 이후 에너지는 성장에 사용하지 않음

권장안은 토큰이 버려졌다는 느낌을 막는다. 첫 버전에서는 친밀도를 기록과 개인
최고로만 사용하고, 장식 보상은 후속 기능으로 둔다.

## 아트·UI 전 결정

### D7. 단계와 등급 이름

권장안:

- Egg / Hatchling / Junior / Adult
- Normal / Rare / Epic / Legendary
- 한국어: 알 / 해츨링 / 주니어 / 어덜트, 일반 / 희귀 / 영웅 / 전설

한국어 단계명을 `새끼`, `성장기`, `완전체`처럼 더 자연스럽게 바꿀 수 있다.
내부 영어 키는 구현 전에 확정해야 한다.

### D8. 첫 아트 범위

권장안:

- 공통 알 1 + 3단계 × 4등급 = 13개 시트
- 색 교체만 하지 않고 등급별 실루엣 차이
- 기존 6개 행동 행 유지

축소안:

- 4개 기본 단계 시트 + 등급 오버레이/파티클

권장안이 수집 재미는 강하지만 제작량이 크다. 축소안은 빠르지만 등급별 외형
차이가 약해질 수 있다.

### D9. 게임 알림 기본값

권장안:

- 기본 꺼짐
- 사용자가 별도로 진화/새 등급 알림을 켤 수 있음

메뉴 바 유틸리티가 불필요한 알림을 늘리지 않게 하는 선택이다.

```

나머지는 권장안
```
