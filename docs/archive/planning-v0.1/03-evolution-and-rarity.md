# 성장 단계, 진화, 등급

## 1. 성장 단계

| 단계 | 누적 성장 에너지 | 역할 |
| --- | ---: | --- |
| Egg / 알 | 0 | 새 세대 시작, 등급은 Normal |
| Hatchling / 해츨링 | 80 | 첫 부화와 첫 등급 판정 |
| Junior / 주니어 | 280 | 실루엣이 크게 변하는 중간 진화 |
| Adult / 어덜트 | 800 | 최종 진화, 육성 완료 가능 |

단계 명칭은 코드와 에셋 식별자에서는 영어를 쓰고 UI에서는 한국어·영어를
현지화한다. 기존의 `baby` 단계는 의미가 겹치므로 마이그레이션 때 `junior`로
바꾸는 기준안이다.

## 2. 예상 성장 기간

매일 같은 토큰을 쓴다는 단순 가정의 참고값이다.

| 일일 토큰 | 일일 에너지 | 해츨링 | 주니어 | 어덜트 |
| ---: | ---: | ---: | ---: | ---: |
| 10,000 | 15 | 6일 | 19일 | 54일 |
| 25,000 | 32 | 3일 | 9일 | 25일 |
| 50,000 | 50 | 2일 | 6일 | 16일 |
| 100,000 | 74 | 2일 | 4일 | 11일 |
| 250,000 | 110 | 1일 | 3일 | 8일 |
| 500,000 | 140 | 1일 | 2일 | 6일 |
| 1,000,000 | 171 | 1일 | 2일 | 5일 |

고사용량일수록 확실히 빨라지지만, 일일 100만 토큰에서도 한 세대에 며칠은
필요하다. 저사용량의 50일 이상이 너무 길다고 판단되면 성장식보다 어덜트 기준을
먼저 낮춰 전체 밸런스를 조정한다.

## 3. 등급

낮은 순서부터 다음 네 단계다.

1. Normal
2. Rare
3. Epic
4. Legendary

UI 표기는 `Normal`, `Rare`, `Epic`, `Legendary`를 기준으로 하고, 한국어 보조
표기는 `일반`, `희귀`, `영웅`, `전설`을 사용한다. 내부 값은 출시 후 저장 데이터와
에셋 이름이 되므로 확정 뒤 바꾸지 않는다.

## 4. 진화 규칙

- 새 알은 Normal에서 시작한다.
- 해츨링, 주니어, 어덜트가 될 때 각각 한 번 등급을 판정한다.
- 판정 결과는 현재 등급과 같거나 높다. 등급은 절대 내려가지 않는다.
- 한 번에 여러 등급이 오를 수 있다.
- Legendary에 도달하면 이후 판정 없이 Legendary를 유지한다.
- 토큰 사용량은 진화 시점만 앞당기며 판정 확률은 바꾸지 않는다.
- 등급이 처음 상승하면 그 등급의 현재 단계뿐 아니라 이전 단계 외형도
  `진화 계보`로 도감에서 함께 해금한다.

### 기본 전이 확률

| 현재 등급 | 유지 | Rare로 | Epic으로 | Legendary로 |
| --- | ---: | ---: | ---: | ---: |
| Normal | 75.0% | 21.0% | 3.8% | 0.2% |
| Rare | 86.0% | - | 13.0% | 1.0% |
| Epic | 97.0% | - | - | 3.0% |
| Legendary | 100% | - | - | - |

천장이 개입하지 않고 Normal 알에서 세 번 판정했을 때 어덜트 최종 분포는
대략 다음과 같다.

| 최종 등급 | 확률 |
| --- | ---: |
| Normal | 42.2% |
| Rare | 40.9% |
| Epic | 15.5% |
| Legendary | 1.4% |

Normal이 실패가 되지 않도록 도감의 육성 완료 횟수와 변형 외형을 별도로 보여
주되, 장기적으로 높은 등급을 확실히 만날 수 있게 천장을 둔다.

### 진화 계보 해금

실제로 만난 외형과 도감에서 볼 수 있는 계보 외형을 구분한다. 예를 들어 Normal
해츨링이 주니어 진화에서 Epic이 되었다면 Epic 주니어는 `만남`으로 기록하고
Epic 해츨링은 같은 등급의 이전 형태로 `계보 해금`한다. Legendary가 어덜트에서
처음 나와도 Legendary 해츨링·주니어·어덜트 세 외형을 모두 감상할 수 있다.

이 규칙이 없으면 첫 판정에서 0.2%인 Legendary 해츨링이 도감 완성의 병목이 된다.
도감에는 만난 횟수와 계보 해금을 서로 다른 표식으로 보여 정확성을 유지한다.

## 5. 천장 규칙 기준안

천장 카운터는 어덜트를 완성했을 때만 갱신한다. 중간에 새 알로 바꾸는 행위는
카운터를 올리지 않는다.

- Rare 이상: 직전 2세대가 모두 최종 Normal이면 다음 어덜트는 최소 Rare
- Epic 이상: 직전 6세대에 Epic 이상이 없으면 다음 어덜트는 최소 Epic
- Legendary: 직전 15세대에 Legendary가 없으면 다음 어덜트는 Legendary

즉, 시작점을 포함해 각각 3번째, 7번째, 16번째 어덜트 안에는 해당 등급 이상을
보장한다.

여러 보장이 동시에 걸리면 가장 높은 보장만 적용한다. 보장은 최종 진화 판정의
결과를 최소 등급까지 올리는 방식이며, 중간 단계 확률은 바꾸지 않는다.

카운터 초기화:

- Rare 이상 완성 시 Rare 카운터 0
- Epic 이상 완성 시 Epic 카운터 0
- Legendary 완성 시 Legendary 카운터 0
- 높은 등급은 그 아래 등급 카운터도 함께 초기화

천장 수치는 설정 화면에 정확한 숫자로 공개한다. 숨겨진 확률이나 원격 변경은
두지 않는다.

## 6. 결과 확정과 연출

진화는 다음 순서의 단일 트랜잭션으로 처리한다.

1. 지급할 성장 에너지와 새 단계 확인
2. 저장된 RNG 상태 또는 시스템 난수로 등급 판정
3. 현재 펫, 도감 발견, 진화 이벤트를 원자적으로 저장
4. 저장 성공 후 UI에 진화 애니메이션 표시
5. 저장 실패 시 기존 상태 유지, 다음 실행에서 안전하게 재시도

결과를 먼저 보여 주고 나중에 저장하지 않는다. 앱 강제 종료가 무료 재추첨으로
작동해서는 안 된다.

한 번의 지연 지급으로 여러 임계점을 넘더라도 세 단계 판정을 순서대로 모두
수행하고 각 발견을 기록한다. UI에서는 연출을 차례대로 재생하거나 요약할 수 있다.

## 7. 난수와 오프라인 앱의 한계

- 암호학적으로 안전한 시스템 난수를 사용한다.
- 판정 결과와 고유 진화 이벤트 ID를 즉시 저장한다.
- 테스트에서는 주입 가능한 결정적 RNG로 경계와 천장을 검증한다.
- 로컬 파일을 사용자가 직접 수정하거나 백업 복원하는 것까지 막는 안티치트는
  만들지 않는다. 경쟁과 과금이 없는 싱글 플레이이므로 데이터 안전성을 우선한다.
