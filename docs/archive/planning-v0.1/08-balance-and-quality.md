# 밸런스 검증, 품질 기준, 위험 관리

## 1. 밸런스 목표

- 첫 진화는 보통 1~3일 안에 경험
- 중간 사용자는 어덜트까지 약 1~3주
- 고사용량 사용자는 더 빠르되 하루 만에 세대를 반복 완성하기 어려움
- 저사용량도 진척이 멈추지 않음
- Normal 어덜트가 반복되어도 3번째 안에 Rare 이상 보장
- Epic은 장기 목표지만 수개월간 전혀 못 보는 상황 방지
- Legendary는 희귀하되 천장으로 유한한 최악의 경우 제공

## 2. 시뮬레이션 입력

서버 텔레메트리 없이 합성 시나리오와 사용자의 로컬 기록으로 검증한다.

### 합성 일일 토큰 패턴

- 매우 낮음: 5천~15천
- 낮음: 15천~40천
- 중간: 40천~120천
- 높음: 120천~400천
- 매우 높음: 400천~200만
- 폭발형: 평일 0~30천, 특정 날 100만 이상
- 다중 제공자: 같은 총량을 2~5개 소스에 분산

확인할 결과:

- 해츨링/주니어/어덜트 도달 일수의 중앙값과 범위
- 30일·90일 내 완료 세대 수
- 등급별 최초 발견까지의 세대 수
- 천장 적용 전후 최악의 연속 실패
- 제공자 분산 여부에 따른 성장량 차이

## 3. 확률 시뮬레이션

최소 100만 가상 세대를 대상으로 다음을 확인한다.

- 전이 행의 합이 정확히 1인지
- 등급 하락이 발생하지 않는지
- 기본 최종 분포가 계산값과 허용 오차 안인지
- 각 천장이 약속한 최대 세대를 넘지 않는지
- 여러 천장이 겹칠 때 가장 높은 보장이 적용되는지
- 결정적 시드에서 실행 순서가 달라도 같은 결과인지

시뮬레이터는 배포 앱에 숨은 확률 조정 기능으로 넣지 않고 테스트 도구로만 둔다.

## 4. 성장 계산 테스트

### 단위 테스트

- 0 토큰은 0 에너지
- 토큰 증가에 따라 에너지가 감소하지 않음
- 큰 값에서도 오버플로 없음
- 같은 일간 누적을 반복 관측해도 한 번만 지급
- 제공자별 델타를 합친 뒤 공식을 한 번 적용
- 누적값 감소 시 회수하지 않음
- 소스 키 변경 시 새 기준선 생성
- 날짜 변경과 시간대 변경에서 중복 없음
- 3일 이내 지연 버킷 반영, 그 밖의 값 보류
- 비정상 점프 2회 확인 규칙

### 속성 테스트

- 모든 `T2 >= T1 >= 0`에 대해 `G(T2) >= G(T1)`
- 지급 에너지 합은 날짜별 최종 목표를 넘지 않음
- 같은 관측 이벤트의 임의 순열 결과가 동일
- 저장/로드 왕복 후 상태와 판정이 동일
- 어덜트 이후 새 에너지가 친밀도에 한 번만 반영됨

## 5. 저장과 마이그레이션 테스트

- 빈 파일, 잘린 JSON, 알 수 없는 미래 스키마
- v1의 각 단계와 경계 XP
- 쓰기 중 강제 종료
- 진화 저장 후 연출 전 종료
- 여정 마치기 저장 중 종료
- 백업 생성 실패와 디스크 용량 부족
- 중복 이벤트 ID
- 잘못된 등급/단계 조합
- 에셋 매니페스트 누락과 PNG 손상

손상 시 앱 전체가 종료되지 않고 기존 상태 바 기능은 계속 사용할 수 있어야 한다.

## 6. UX 검증 시나리오

- 처음 설치하고 오늘 토큰이 이미 있는 사용자
- 토큰 제공자를 하나도 연결하지 않은 사용자
- 지원되지 않는 세션 범위만 있는 사용자
- 여러 제공자 중 하나만 오류인 사용자
- 진화 순간 앱을 닫은 사용자
- Normal이 두 번 연속 나온 사용자
- 중도 이별하려는 사용자
- 어덜트와 계속 함께한 뒤 같은 날 새 알을 받는 사용자
- 마지막 진화에서 처음 Legendary가 되어 이전 계보가 함께 해금된 사용자
- 모션 감소와 VoiceOver 사용자
- 저전력 모드에서 Legendary를 발견한 사용자

각 시나리오에서 “무슨 일이 일어났는지, 무엇이 유지되는지, 다음에 무엇을 할 수
있는지”를 한 화면 안에서 설명할 수 있어야 한다.

## 7. 주요 위험과 완화

| 위험 | 영향 | 완화 |
| --- | --- | --- |
| 토큰 범위 혼합 | 중복·폭증 | 명시적 관측 범위와 안정 키 |
| 값 지연/역행 | 성장 불신 | 회수 금지, 확인 후 반영, 상태 문구 |
| 토큰 낭비 유인 | 비용·환경 부담 | 한계효용 감소, 경쟁·미션·확률 보너스 없음 |
| 저사용자 과도한 대기 | 이탈 | 임계점 조정, 첫 진화 빠르게 유지 |
| 고사용자 콘텐츠 소진 | 수집 목표 소진 | 여러 세대·천장·도감, 향후 계열 확장 |
| 낮은 등급 좌절 | 반복 초기화 | 하락 없음, 공개 천장, 발견 기록 유지 |
| 저장 손상 | 진행 유실 | 원자 쓰기, 백업, 이벤트 ID |
| 에셋 제작량 | 일정 지연 | 정지 프레임 승인 후 애니메이션 |
| 색상 의존 | 접근성 저하 | 실루엣·배지·텍스트 병행 |
| 기능 비선호 | 유틸리티 가치 저하 | 완전한 끄기, 기존 UI 우선 |
