# 새 알, 여정 마치기, 도감

## 1. 용어

“초기화”는 설정 전체 삭제처럼 들리므로 게임 UI에서는 사용하지 않는다.

- 새 알 받기: 현재 개체의 성장을 끝내고 다음 세대를 0 에너지에서 시작
- 여정 마치기: 어덜트를 도감의 육성 완료 기록에 남기고 새 알 받기
- 중도 이별: 어덜트 이전에 현재 성장을 포기하고 새 알 받기
- 전체 게임 데이터 삭제: 설정의 위험 작업. 펫·도감·천장을 모두 삭제

## 2. 어덜트 이후 선택

어덜트에 도달해도 자동으로 사라지지 않는다.

### 계속 함께하기

- 현재 어덜트 외형을 메뉴 바에 유지한다.
- 이후 토큰 에너지는 해당 개체의 `친밀도 에너지`에 계속 누적한다.
- 친밀도는 등급, 천장, 다음 알의 성장에 영향을 주지 않는다.
- 첫 버전에서는 친밀도 수치와 개인 최고 기록만 제공하고 장식은 후속 후보로 둔다.
- 새 알을 시작하기 전까지 쌓인 친밀도는 다음 알로 이전되지 않는다.

### 여정 마치기

- 최종 등급, 완료 시각, 세대 번호를 육성 완료 기록에 추가한다.
- 해당 개체의 최종 친밀도와 개인 최고 여부를 기록한다.
- 천장 카운터를 최종 등급에 따라 갱신한다.
- 확인 후 새 Normal 알을 만든다.
- 그날 이후 새로 발생하는 토큰 증가분부터 새 알에 반영한다.

어덜트가 된 뒤의 에너지는 친밀도로 이미 사용된 것이므로 다음 펫에 다시 쓰지
않는다.

## 3. 중도 이별

사용자가 낮은 등급에 만족하지 못하면 어느 단계에서든 새 알을 받을 수 있다.

유지되는 것:

- 이미 발견한 단계·등급 도감 항목
- 이전 어덜트 육성 완료 기록
- 기존 천장 카운터
- 앱의 사용량 기록과 일반 설정

사라지는 것:

- 현재 개체의 누적 성장 에너지
- 아직 어덜트가 아닌 현재 개체의 육성 완료 기록
- 현재 개체의 다음 진화 기회

변하지 않는 것:

- 중도 이별은 천장을 올리지도 초기화하지도 않는다.
- 같은 날 이미 지급한 에너지는 새 알에 다시 지급되지 않는다.

확인 창에는 현재 단계, 등급, 잃는 에너지, 다시 사용할 수 없는 오늘 에너지를
명시한다. 기본 버튼은 취소다.

이 규칙은 사용자의 선택권을 보장하면서 알을 반복 생성해 즉시 희귀 등급을 뽑는
리롤을 막는다. 등급 판정에는 실제 성장 임계점까지 다시 도달해야 한다.

## 4. 도감의 두 종류 진척

### 도감 해금

진화 과정에서 화면에 나타난 단계·등급 조합은 `만남`으로 등록한다. 등급이
상승하면 같은 등급의 이전 단계 외형은 `진화 계보`로 함께 해금한다.

- 잠김/발견 상태
- 실제 만남 또는 계보 해금 상태
- 최초 발견 시각
- 마지막 발견 시각
- 발견 횟수
- 정지 이미지와 등급 설명

중도 이별을 해도 발견은 취소되지 않는다.

### 육성 기록

어덜트 여정을 마친 세대만 기록한다.

- 총 완료 세대 수
- 등급별 완료 수
- 최고 등급
- 어덜트 친밀도 개인 최고
- 최초/최근 완료 시각
- 현재 천장 진행

개별 세대의 긴 목록은 첫 버전에서 보관하지 않고 최근 20개의 요약만 두는
기준안이다. 무제한 로그가 필요하면 내보내기 기능과 함께 후속 버전에서 검토한다.

## 5. 도감 범위

초기 ByteBot 계열은 다음 13개 시각 항목을 갖는다.

- 공통 Normal 알 1개
- 해츨링 4등급
- 주니어 4등급
- 어덜트 4등급

도감 완성률은 `해금한 항목 / 13`으로 계산한다. 알에서 아직 판정하지 않은
Rare/Epic/Legendary 변형은 만들지 않는다.

같은 외형을 다시 만나도 중복 재화로 바꾸지 않는다. 대신 발견 횟수가 올라가고
해당 등급 육성 기록이 쌓인다. 경제 시스템을 만들지 않아 첫 버전의 복잡도를
제한한다.

## 6. 천장과 도감의 관계

도감 화면에서 다음 보장까지 남은 어덜트 수를 보여 준다.

- Rare 이상: 최대 N세대 이내
- Epic 이상: 최대 N세대 이내
- Legendary: 최대 N세대 이내

정확한 다음 판정 결과나 숨은 난수는 보여 주지 않는다. 천장은 “언젠가”가 아니라
최악의 경우를 이해할 수 있게 한다.

## 7. 전체 삭제

설정의 전체 게임 데이터 삭제는 다음을 제거한다.

- 현재 펫
- 발견 도감과 육성 기록
- 천장 카운터
- 성장 반영 원장

일반 사용량 기록까지 함께 삭제할지는 별도 체크박스로 분리한다. 두 단계 확인과
삭제 대상 목록을 제공하며, 가능하면 삭제 전 로컬 백업 내보내기를 제안한다.
