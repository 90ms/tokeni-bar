> 상태: 폐기된 검토용 v0.1 — 역사 자료로만 보존
> 작성일: 2026-07-26

이 디렉터리는 현재 구현 전에 작성된 초기 제안과 당시의 결정 기록을 보존합니다.
성장식, 펫 단계, 등급 및 초기화 방식 등은 현재 제품과 다르므로 구현 기준으로
사용하지 않습니다. 현재 사양은 [Tokeni 펫 성장과 알 도감](../../bytebot.ko.md)과
[Tokeni 펫 시스템 정책](../../companion-policy.ko.md)을 따릅니다.

## 한 문장 정의

Tokeni Bar에서 실제로 관측된 에이전트 토큰 사용량이 ByteBot의 성장 에너지로
바뀌고, 진화 때마다 더 높은 등급의 외형을 얻을 기회가 생기며, 완성한 개체와
발견한 외형을 도감에 모으는 로컬 싱글 플레이 수집 게임이다.

## 기획 원칙

1. 토큰 누적이 커질수록 더 많은 성장 에너지를 얻고 상한에 막히지 않는다.
2. 일일 하드캡은 두지 않는다. 초고사용량 구간은 증가폭만 완만해진다.
3. 토큰량은 진화 속도에 영향을 주지만 등급 주사위 자체를 유리하게 만들지 않는다.
4. 쉬는 날, 사용량 감소, 연속 접속 실패로 펫이 죽거나 퇴화하지 않는다.
5. 관측이 불완전하면 성장을 보류하며 값을 만들어 내지 않는다.
6. 진화 등급은 오르기만 하고 내려가지 않는다.
7. 낮은 등급을 다시 키울 수 있지만, 조기 초기화가 확률을 악용하는 지름길이 되지는 않는다.
8. 모든 게임 데이터는 로컬에 저장하며 프롬프트, 응답, 인증 정보는 사용하지 않는다.
9. 색상만 바꾼 외형이 아니라 실루엣과 장식에서도 등급을 구분할 수 있게 한다.
10. 게임 기능을 꺼도 기존 상태 표시 기능은 그대로 동작해야 한다.

## 당시 기준안 요약

| 항목 | 기준안 |
| --- | --- |
| 성장 입력 | 지원하는 모든 에이전트의 신뢰 가능한 토큰 사용량 합계 |
| 성장식 | `floor(32 × log2(1 + 오늘 토큰 / 25,000))` |
| 일일 제한 | 없음 |
| 단계 | 알 → 해츨링 → 주니어 → 어덜트 |
| 누적 성장 에너지 | 0 → 80 → 280 → 800 |
| 등급 | Normal → Rare → Epic → Legendary |
| 등급 변화 | 세 번의 진화마다 현재 등급 이상으로 재추첨 |
| 최종 기본 분포 | Normal 42.2%, Rare 40.9%, Epic 15.5%, Legendary 1.4% |
| 천장 | Rare 3회, Epic 7회, Legendary 16회 안에 보장하는 기준안 |
| 낮은 등급 재시작 | 가능. 현재 성장 포기, 천장 진척 없음 |
| 어덜트 은퇴 | 도감의 육성 완료 횟수에 기록 후 새 알 시작 |
| 어덜트 이후 성장 | 추가 에너지는 해당 개체의 친밀도로 누적 |
| 초기 콘텐츠 | ByteBot 1종, 알 1개 + 3단계 × 4등급 외형 |
| 페널티 | 죽음, 퇴화, 성장 감소, 스트릭 상실 없음 |
