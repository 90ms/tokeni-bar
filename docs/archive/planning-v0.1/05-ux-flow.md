# 메뉴 바 UX와 상태 흐름

## 1. 기본 원칙

- 펫 카드는 기존 제공자 사용량보다 시각적으로 크지 않게 유지한다.
- 숫자는 “오늘 토큰 → 오늘 에너지 → 다음 진화” 관계를 설명할 수 있어야 한다.
- 게임 기능을 원하지 않는 사용자는 설정에서 완전히 숨길 수 있다.
- 색상, 애니메이션, 소리만으로 중요한 결과를 전달하지 않는다.
- 오류 상태에서는 성장량을 추정하지 않고 왜 보류됐는지 알려 준다.

## 2. 기본 펫 카드

펫 카드의 기본 정보 우선순위:

1. 현재 스프라이트
2. 이름, 단계, 등급
3. 다음 진화 진행 바와 `현재 에너지 / 필요 에너지`
4. `오늘 +N 에너지 · 토큰 M`
5. 현재 행동 문구
6. 쓰다듬기 버튼

어덜트에서는 다음 진화 진행 바를 없애고 다음 두 동작을 제공한다.

- 현재 친밀도 에너지와 개인 최고
- 계속 함께하기
- 여정 마치고 새 알 받기

카드 자체를 클릭하면 상세 팝오버로 이동하고, 도감은 상세 화면의 탭으로 둔다.
메뉴 바 첫 화면에 모든 확률과 기록을 노출하지 않는다.

## 3. 성장 상태

### 정상 반영

```text
오늘 100,240 토큰 → +74 에너지
다음 진화까지 126
```

토큰 값은 여러 제공자의 검증된 합계다. 카드에서는 제공자별 기여를 나누지 않고,
상세 설명에서만 “3개 중 2개 제공자 반영”처럼 상태를 보여 준다.

### 아직 사용 없음

```text
오늘 관측된 토큰이 없어요
에이전트를 사용하면 ByteBot이 성장해요
```

### 일부 제공자 보류

```text
확인 가능한 토큰만 반영했어요
Gemini의 세션 범위를 확인하는 중
```

보류 중인 값을 추정해서 합치지 않는다. 해당 제공자 설정이나 진단 화면으로
이동하는 링크를 제공한다.

### 데이터 오래됨

```text
성장 데이터가 오래되었어요
새로고침하면 다시 확인할게요
```

기존 에너지와 펫 상태는 유지한다.

### 일간 값 감소

```text
토큰 집계가 갱신되어 확인 중이에요
이미 얻은 에너지는 사라지지 않아요
```

## 4. 진화 흐름

1. 카드가 짧게 빛나고 “진화 준비 완료” 상태가 된다.
2. 모션이 허용되면 1.5~2.5초 변환 애니메이션을 재생한다.
3. 새 단계, 새 등급, 새 외형을 동시에 공개한다.
4. 등급이 올랐다면 상승 전후를 명시한다.
5. 새 도감 항목이면 `NEW` 배지와 도감 이동 버튼을 표시한다.
6. 닫으면 일반 카드로 돌아간다.

진화 결과 저장은 이 흐름 전에 완료되어야 한다. 앱을 다시 열면 보지 못한
진화 결과를 한 번만 다시 안내한다.

여러 단계가 한 번에 열린 경우:

- 최대 3개의 결과 카드를 순서대로 넘긴다.
- “모두 보기”로 요약할 수 있다.
- 각 단계의 등급 판정과 도감 발견은 생략하지 않는다.

## 5. 등급 표현

| 등급 | 텍스트 | 배지 형태 | 보조 표현 |
| --- | --- | --- | --- |
| Normal | 일반 | 원 | 기본 테두리 |
| Rare | 희귀 | 마름모 | 이중 테두리 |
| Epic | 영웅 | 육각형 | 별 장식 |
| Legendary | 전설 | 왕관형 | 전용 광륜 |

정확한 색은 아트 단계에서 정하되, 색이 보이지 않아도 형태와 텍스트로 구분한다.
Legendary의 반짝임은 모션 감소 설정에서 정적 광륜으로 대체한다.

## 6. 도감 화면

상단 요약:

- `발견 7 / 13`
- `완료한 세대 4`
- `최고 등급 Epic`
- `최고 친밀도 842`
- 각 천장까지 남은 최대 세대 수

그리드:

- 행: 해츨링, 주니어, 어덜트
- 열: Normal, Rare, Epic, Legendary
- 미해금 항목은 실루엣과 `???`
- 실제 만남과 진화 계보 해금을 서로 다른 작은 배지로 표시
- 공통 알은 그리드 앞에 별도 표시

항목 상세:

- 큰 정지 스프라이트
- 최초 발견일
- 발견 횟수
- 해당 어덜트 육성 완료 횟수
- 등급의 기본 확률 설명

## 7. 알 교체 확인

중도 이별 확인문 예:

```text
이 ByteBot과 이별하고 새 알을 받을까요?

현재: 주니어 · Normal · 413 에너지
잃게 되는 성장: 413
도감 발견 기록과 기존 천장은 유지됩니다.
중도 이별은 천장을 앞당기지 않습니다.
```

버튼:

- 취소
- 이별하고 새 알 받기

파괴적인 버튼은 빨간색과 명확한 동사를 사용하며 기본 포커스를 받지 않는다.

## 8. 알림

기본적으로 시스템 알림을 추가로 켜지 않는다. 기존 사용량 알림 설정과 게임 알림을
분리한다.

선택 가능한 게임 알림 후보:

- 진화 가능 또는 자동 진화 완료
- 새 등급 발견
- Legendary 발견

성장 에너지의 작은 증가마다 알림을 보내지 않는다. 메뉴 카드의 애니메이션과
숫자 갱신으로 충분하다.

## 9. 접근성과 환경 설정

- Reduce Motion: 프레임 애니메이션과 화면 흔들림 대신 페이드
- 저전력 모드: 정적 첫 프레임, 결과 텍스트는 동일
- VoiceOver: `ByteBot, 주니어, 희귀, 다음 진화까지 126 에너지`
- 키보드: 도감 그리드, 확인 창, 탭 순서 지원
- 현지화: 확률 숫자와 등급 내부 키를 제외한 모든 문구 번역
- 숫자: 로캘별 자릿수 구분, 매우 큰 토큰은 상세에서 정확한 값 제공
