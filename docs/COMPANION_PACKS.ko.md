# 로컬 펫 팩 가져오기

**한국어** | [English](COMPANION_PACKS.md)

Tokeni는 Codex Pets V1/V2 형식의 로컬 ZIP을 외부 외형으로 가져올 수 있습니다.
외부 외형은 대표 펫의 그림과 행동 애니메이션만 바꾸며 종, 성장 XP, 레벨,
희귀도, 알 확률과 도감 진행에는 영향을 주지 않습니다.

## 가져오고 적용하기

1. 사용 권한을 확인한 Codex 호환 펫 ZIP을 Mac에 저장합니다.
2. Tokeni 창에서 **펫 → 펫 팩 → 팩 가져오기…**를 선택합니다.
3. 필요하면 작성자, 원본 URL, 라이선스와 고지문을 입력합니다.
4. **검증 후 설치**를 선택합니다.
5. 설치된 카드에서 **외형 사용**을 선택합니다.

적용한 외형은 대표 펫, 메뉴바 요약과 화면 위 펫에 함께 반영되고 다음 실행에도
유지됩니다. 보관 중인 다른 펫을 미리 볼 때는 그 펫의 원래 외형을 보여 줍니다.
**원래 외형 사용**을 선택하면 성장 데이터 변경 없이 즉시 되돌아갑니다.

팩 삭제는 로컬 그림과 메타데이터만 지웁니다. 사용 중인 팩을 삭제하면 원래
외형으로 돌아가며 펫과 성장 기록은 보존됩니다.

## 지원하는 ZIP 구조

ZIP 루트에는 다음 두 파일만 있어야 합니다.

```text
pet.json
spritesheet.webp   # 또는 spritesheet.png
```

하위 폴더, 암호화 파일, 심볼릭 링크, 실행 파일과 추가 파일은 허용하지 않습니다.
ZIP64는 지원하지 않습니다. 압축 파일은 최대 64 MiB, 해제 후 전체 크기는 최대
256 MiB이며 비정상적으로 높은 압축률도 거부합니다.

`pet.json`의 최소 예시는 다음과 같습니다.

```json
{
  "id": "my-pet",
  "displayName": "My Pet",
  "description": "Optional short description",
  "spritesheetPath": "spritesheet.webp",
  "spriteVersionNumber": 2
}
```

- `id`는 영문·숫자로 시작하고 영문, 숫자, `.`, `_`, `-`만 사용합니다.
- `spritesheetPath`는 루트의 `spritesheet.webp` 또는 `spritesheet.png`와 정확히
  일치해야 합니다.
- 버전을 생략하거나 `1`로 지정하면 V1, `2`로 지정하면 V2입니다.
- V1은 `1536×1872`(8열×9행), V2는 `1536×2288`(8열×11행)입니다.
- 프레임 하나의 크기는 `192×208`이며 Tokeni는 이 비율을 유지합니다.

## 행동 매핑

| Tokeni 행동 | Codex 행 |
| --- | --- |
| 기본 | Idle |
| 작업 | Review |
| 대기 | Waiting |
| 경고 | Failed |
| 축하·시그니처 | Waving |
| 수면 | Idle 첫 프레임 |

V1과 V2의 첫 9개 행동 행 계약은 같습니다. V2의 추가 방향 행은 현재 대표 펫
행동에 사용하지 않습니다.

## 권리와 개인정보

- 다운로드할 수 있다는 사실만으로 재배포나 파생 작업 권한이 생기지는 않습니다.
- 라이선스가 없으면 Tokeni는 `미지정 · 로컬 사용`으로 표시합니다.
- 유명 인물, 브랜드 또는 보호되는 캐릭터는 권리를 확인한 뒤 사용하세요.
- 팩은 이 Mac의 Application Support에만 저장되며 Tokeni가 외부 갤러리에
  업로드하지 않습니다.
- 팩 메타데이터에는 제공자 이름, 토큰 합계, 프롬프트, 응답 또는 인증정보를
  기록하지 않습니다.

참고 형식은 [Codex Pets 공개 저장소](https://github.com/astandrik/codex-pets)를
기준으로 하며, Tokeni는 해당 서비스와 독립적인 로컬 호환 기능을 제공합니다.
