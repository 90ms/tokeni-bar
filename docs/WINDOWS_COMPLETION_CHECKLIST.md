# Windows completion work

This checklist tracks the follow-up to the first native desktop GUI.

- [ ] Consistent native visual design, Korean/English, system/light/dark appearance
- [ ] Usage history, provider/range filtering, chart and detailed records
- [ ] Companion preview, collection, names/roles, eggs, shop and rewards
- [ ] Overlay movement, size, click-through and motion settings
- [ ] Per-user installer, shortcuts, uninstall and version metadata
- [ ] Update checking, verified installation and rollback
- [ ] Native control, persistence, installer/update and package tests
- [ ] Interactive Windows verification and recorded limitations
- [ ] Signing integration ready; public signing requires the user's certificate/service

Existing uncommitted signing work is preserved until reviewed as part of distribution.
Changes are committed in functional units on `codex/windows-desktop-app`.
No release tag or main merge is implied by this implementation work.
