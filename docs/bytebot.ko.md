# Tokeni 펫 성장과 도감

**한국어** | [English](bytebot.md)

Tokeni 펫은 Tokeni Bar가 확인한 에이전트 토큰 사용량으로 성장하는 로컬 픽셀
동반자입니다. 별도의 계정이나 서버가 없으며 종류, 성장, 등급, 도감과 보장은 모두
Mac에 저장됩니다.

## 성장 에너지

오늘 여러 제공자의 확인된 토큰 증가분을 중복 지급 없이 합산한 값을 `T`라고
할 때 오늘의 성장 에너지는 다음과 같습니다.

```text
T = 0  → 0
T > 0  → floor(32 × log2(1 + T / 25,000))
```

토큰을 더 사용하면 오늘의 에너지 목표가 계속 올라가지만, 초고사용량 구간에서는
에너지 1에 필요한 추가 토큰이 늘어납니다. 실제 행동 에너지 잔액은 최대
320입니다.

| 오늘 토큰 | 오늘 에너지 |
|---:|---:|
| 10,000 | 15 |
| 25,000 | 32 |
| 50,000 | 50 |
| 100,000 | 74 |
| 250,000 | 110 |
| 500,000 | 140 |
| 1,000,000 | 171 |

같은 누적값은 새로고침해도 한 번만 반영됩니다. 날짜가 바뀔 때마다 남은
잔액의 20%만 이월되며, 여러 날 앱을 열지 않았다면 날짜별로 20%가 순차
적용됩니다.

펫 도감의 **행동 에너지**에는 오늘 성장에 반영된 제공자별 토큰, 합계, 오늘
에너지 목표와 다음 에너지 1에 필요한 추가 토큰이 표시됩니다. 완전한 일일 합계를
제공하지 않는 CLI는 Tokeni Bar가 실행 중 확인한 세션·누적 증가분만 표시합니다.
아직 신뢰할 수 있는 값이 없는 제공자는 0으로 표시하지 않고 **확인 대기**로
구분합니다.

Codex의 계정 일일 합계는 다음날 도착할 수 있습니다. 최근 3일 안의 확정값은
원래 사용 날짜의 성장 공식으로 계산하되 확인된 날의 행동 에너지에 지급합니다.
제공자별 내역에는 사용 날짜와 오늘 정산·오늘 집계 대기 상태가 함께 표시됩니다.

## 성장 단계

| 행동 | 소비 에너지 |
|---|---:|
| 알 부화 | 60 |
| 주니어 진화 | 100 |
| 성체 진화 | 160 |
| 성체 여정 마치고 새로 부화하기 | 100 |
| 성체 전 새 알 받기·초기화 | 40 |

처음에는 등급 없는 알이며, 에너지가 충분해도 자동으로 다음 단계가 되지
않습니다. 사용자가 부화 또는 진화 버튼을 눌러야 에너지가 소비되고 단계가
바뀝니다. 성체 이후 얻는 에너지는 행동 잔액과 해당 펫의
**친밀도 에너지**에 함께 반영됩니다.

작업 중, 쿼터 경고, 토닥하기, 장시간 비활동에 따라 스프라이트 동작이 바뀝니다.
활동 감지는 동작에만 사용하며 성장 에너지를 만들지는 않습니다.

## 등급과 진화

알은 종류를 알 수 없는 공통 모습입니다. 직접 부화할 때 아래 다섯 종류와 첫
등급이 서로 독립적으로 결정됩니다.

| 종류 | 개성 | 기본 확률 |
|---|---|---:|
| ByteBot | 성실한 꼬마 로봇 | 20% |
| CacheCat | 호기심 많은 데이터 고양이 | 20% |
| StackFox | 영리한 코드 여우 | 20% |
| PromptPup | 낙천적인 프롬프트 강아지 | 20% |
| NullSlime | 느긋한 디지털 슬라임 | 20% |

부화한 종류는 주니어와 성체까지 유지됩니다. 미발견 종류가 남아 있는 동안
중복 부화가 5회 연속 발생하면 다음 알은 미발견 종류 중 하나로 확정됩니다.

등급은 부화할 때 처음 결정됩니다. 이후 `일반 → 희귀 → 영웅 → 전설`
순서로 유지되거나 올라가며 내려가지 않습니다.

| 현재 등급 | 유지 | 희귀 | 영웅 | 전설 |
|---|---:|---:|---:|---:|
| 일반 | 75.0% | 21.0% | 3.8% | 0.2% |
| 희귀 | 86.0% | - | 13.0% | 1.0% |
| 영웅 | 97.0% | - | - | 3.0% |
| 전설 | 100% | - | - | - |

천장이 없을 때 알에서 부화한 성체의 최종 분포는 일반 42.2%, 희귀 40.9%,
영웅 15.5%, 전설 1.4%입니다.

낮은 등급이 오래 이어지는 상황을 막기 위해 완성한 성체를 기준으로 다음을
보장합니다.

- 최대 3회 완료 여정 안에 희귀 이상
- 최대 7회 완료 여정 안에 영웅 이상
- 최대 16회 완료 여정 안에 전설

천장은 도감에서 남은 최대 완료 여정 수로 확인할 수 있습니다. 중간에 새 알로
다시 시작해도 기존 천장은 유지되지만 앞당겨지지는 않습니다.

## 도감

도감은 5종 × 부화·주니어·성체 × 4등급 외형, 총 60개로 구성됩니다. 등급이 없는
알은 도감 외형 수에 포함하지 않습니다.

진화에서 직접 본 외형은 **만남**으로 기록됩니다. 높은 등급이 늦은 단계에서
처음 나왔다면 같은 등급의 이전 단계 외형도 **계보**로 해금됩니다. 따라서
전설이 성체에서 처음 나와도 전설 부화와 주니어 외형을 함께 볼 수 있습니다.

메뉴의 격자 버튼 또는 **설정 → Tokeni → 펫 도감 열기**에서 다음을
확인할 수 있습니다.

- 5종의 발견 여부와 부화 만남 횟수
- 60개 외형의 해금 상태
- 실제 만남과 계보 해금 구분
- 완료한 여정, 최고 등급, 최고 친밀도
- 각 등급 천장까지 남은 최대 완료 여정

## 새 알과 여정 마치기

성체가 되면 현재 모습과 계속 함께하며 친밀도를 올리거나, 에너지 100을 사용해
여정을 마치고 새 펫을 즉시 부화할 수 있습니다. 100은 새 알 비용 40과 부화
비용 60의 합계입니다. 완료한 펫의 최종 등급과 친밀도를 기록하고 천장을
갱신한 뒤, 새 펫의 종류와 첫 등급을 한 번에 공개합니다.

성체 이전에도 에너지 40을 사용해 새 알을 받을 수 있습니다.

- 해금한 도감과 기존 천장은 유지됩니다.
- 사용하지 않은 행동 에너지는 유지됩니다.
- 중도 이별은 완료 여정이나 천장 진척으로 계산하지 않습니다.
- 같은 날 이미 사용한 에너지를 새 알에 다시 쓸 수 없습니다.

## 별조각과 출석 보상

별조각은 성장 에너지와 분리된 보상 재화입니다. 성장 에너지는 계속 확인된
토큰 증가분에서만 만들어지며, 출석이나 앱 활동 시간은 성장 에너지를 만들지
않습니다.

| 획득 조건 | 별조각 |
|---|---:|
| 일일 출석 | 10 |
| 같은 주 누적 3일 / 5일 / 7일 | 10 / 20 / 30 |
| 같은 달 누적 20일 | 50 |
| 새로운 펫 종류 최초 발견 | 20 |
| 성체 여정 완료 | 25 |
| 도감 10개 / 30개 / 60개 해금 | 20 / 50 / 100 |

출석은 연속 출석이 아니라 주간·월간 누적 방식입니다. 하루를 놓쳐도 이미
쌓인 횟수는 초기화되지 않습니다. 한 로컬 날짜에는 한 번만 받을 수 있고,
시스템 날짜가 마지막 출석일보다 과거로 이동하면 날짜가 정상화될 때까지
수령할 수 없습니다.

업데이트 전에 이미 달성한 펫 발견, 완료 여정과 도감 단계는 보상 상태를 처음
불러올 때 한 번만 소급 지급합니다. 이후 같은 기록을 다시 읽어도 중복
지급하지 않습니다.

### 별조각 꾸미기

펫 도감에서 별조각으로 다음 꾸미기를 영구 해금할 수 있습니다.

| 꾸미기 | 가격 |
|---|---:|
| 반짝임 오라 | 별조각 60개 |
| 별 왕관 | 별조각 120개 |
| 밤하늘 링 | 별조각 200개 |

구매한 꾸미기는 자유롭게 착용하거나 해제할 수 있습니다. 선택한 꾸미기는 메뉴
팝오버, 도감의 현재 펫, 설정 미리보기와 화면 위 펫에 함께 표시됩니다.
꾸미기는 시각 효과일 뿐 성장 에너지, 등급, 진화 확률과 보장에는 영향을 주지
않습니다.

## 메뉴바와 화면 위 표시

메뉴바 단색 상태 아이콘에는 알 부화 또는 부화·주니어 단계 진화에 필요한 행동
에너지가 모였을 때 빨간 뱃지가 표시됩니다. 성체 여정 완료는 별도 선택이므로
이 뱃지에 포함하지 않습니다.

**설정 → Tokeni → 화면 위에 펫 표시**에서는 펫을 투명한 플로팅 패널로
표시할 수 있습니다. 표시 크기, 위치 잠금과 클릭 통과를 선택할 수 있으며,
드래그한 위치는 로컬 설정에 저장됩니다. 펫이 화면 밖에 있거나 모니터 구성이
바뀐 경우 **펫 위치 초기화**로 현재 화면 오른쪽 위에 되돌릴 수 있습니다.

## 토큰을 반영하지 못하는 경우

Tokeni Bar는 값의 범위와 초기화 시점을 확인할 수 있는 토큰만 성장에 씁니다.
데이터가 없거나 오래되었거나 파서가 현재 CLI 형식과 맞지 않으면 임의의 성장량을
만들지 않습니다.

- Codex와 Claude의 완전한 일일 누적은 확인된 사용 날짜에 반영합니다. 최대
  3일 늦게 확인된 합계의 에너지는 확인된 날 지급합니다.
- Gemini와 Grok의 세션 누적, OpenCode의 전체 누적은 첫 관측을 기준선으로 삼고
  이후 증가분부터 반영합니다.
- 앱이 날짜 경계 동안 꺼져 있어 어느 날의 사용인지 알 수 없는 세션·전체 누적은
  소급 추정하지 않습니다.
- 비정상적으로 큰 증가는 다음 관측에서 다시 확인한 뒤 반영합니다.

상세한 집계와 비용 표시 규칙은 [사용량 표시 안내](usage.ko.md)를 참고하세요.

## 저장과 개인정보

종류, 단계, 등급, 에너지, 친밀도, 도감, 보상과 화면 위 펫 설정은 Mac에만
저장됩니다. 집계 사용 기록은 30일 동안 유지되며, 손상된 진행 데이터는 보관된
로컬 복구본으로 자동 복구를 시도합니다.

펫 상태에는 제공자 이름이나 원본 토큰 합계를 넣지 않습니다. 프롬프트, 응답,
인증 토큰, 쿠키 또는 계정 비밀정보도 저장하지 않으며 분석 도구나 서버
텔레메트리는 없습니다.

별도의 게임 서버나 계정이 없는 로컬 앱이므로 진행 데이터는 강한 부정행위
방지 수단이 아닙니다. 일관성 검사와 복구는 우발적인 손상과 중복 반영을 줄이기
위한 것이며, 기기 소유자가 로컬 데이터를 의도적으로 수정하는 것까지 보장하지
않습니다.
