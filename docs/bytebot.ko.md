# Tokeni 펫 성장과 도감

**한국어** | [English](bytebot.md)

Tokeni 펫은 Tokeni Bar가 확인한 에이전트 토큰 사용량으로 성장하는 로컬 픽셀
동반자입니다. 별도의 계정이나 서버가 없으며 종류, 성장, 등급, 도감과 보장은 모두
Mac에 저장됩니다.

## 성장 에너지

여러 제공자의 확인된 토큰 증가분을 중복 지급 없이 합산한 값을 `T`라고 할 때
성장 에너지는 다음과 같습니다.

```text
성장 에너지 = floor(T / 100,000)
```

| 검증된 토큰 | 성장 에너지 |
|---:|---:|
| 100,000 | 1 |
| 1,000,000 | 10 |
| 10,000,000 | 100 |
| 100,000,000 | 1,000 |
| 300,000,000 | 3,000 |

사용량이 커져도 교환 비율은 달라지지 않습니다. 에너지로 바뀌지 않은 10만 개
미만의 토큰은 날짜를 넘어 원장에 남고, 사용하지 않은 행동 에너지도 100%
유지됩니다. 행동 에너지의 안전 상한은 100,000입니다. 같은 누적값은
새로고침해도 한 번만 반영됩니다.

펫 도감의 **행동 에너지**에는 오늘 성장에 반영된 제공자별 토큰, 합계, 오늘
에너지 목표와 다음 에너지 1에 필요한 추가 토큰이 표시됩니다. 완전한 일일 합계를
제공하지 않는 CLI는 Tokeni Bar가 실행 중 확인한 세션·누적 증가분만 표시합니다.
아직 신뢰할 수 있는 값이 없는 제공자는 0으로 표시하지 않고 **확인 대기**로
구분합니다.

Codex의 계정 일일 합계는 다음날 도착할 수 있습니다. 최근 3일 안의 확정값은
원래 사용 날짜의 성장 공식으로 계산하되 확인된 날의 행동 에너지에 지급합니다.
제공자별 내역에는 사용 날짜와 오늘 정산·오늘 집계 대기 상태가 함께 표시됩니다.

## 성장 단계

| 행동 | 소비 에너지 |
|---|---:|
| 알 부화 | 500 |
| 성장기 진화 | 800 |
| 성체 진화 | 1,400 |
| 성체 여정 마치고 새로 부화하기 | 800 |
| 성체 전 새 알 받기·초기화 | 300 |

처음에는 등급 없는 알이며, 에너지가 충분해도 자동으로 다음 단계가 되지
않습니다. 사용자가 부화 또는 진화 버튼을 눌러야 에너지가 소비되고 단계가
바뀝니다. 성체 이후 얻는 에너지는 행동 잔액과 해당 펫의
**친밀도 에너지**에 함께 반영됩니다.

진화할 때는 이전 모습이 빛 속으로 축소된 뒤 새 단계가 나타납니다. 연출
중에는 진화를 다시 누를 수 없으며, 동작 줄이기나 저전력 모드에서는 즉시
또는 짧은 전환으로 표시됩니다.

작업 중에는 작업 동작을, 최근 활동이 끝난 뒤 2분 동안은 기존 대기 동작을
사용합니다. 이후에는 기본 동작으로 돌아가 가끔 작게 움직이며, 10분 이상
비활동이면 잠듭니다. 쿼터 경고와 토닥하기는 우선순위가 더 높은 별도 동작을
사용합니다. 대기 상태는 실제 네트워크 응답 여부가 아니라 최근 활동을 바탕으로
한 연출입니다.

검증된 토큰이 실제 성장 에너지로 반영되면 펫이 짧게 커지며 반짝입니다. 활동
감지와 모든 시각 반응은 성장 에너지를 만들지 않습니다. 동작 줄이기, 앱의
펫 애니메이션 끄기 또는 저전력 모드에서는 추가 움직임을 재생하지 않습니다.

## 등급과 진화

알은 종류를 알 수 없는 공통 모습입니다. 직접 부화할 때 아래 다섯 종류와 첫
등급이 서로 독립적으로 결정됩니다.

| 종류 | 개성 | 기본 확률 |
|---|---|---:|
| ByteBot | 성실한 꼬마 로봇 | 20% |
| CacheCat | 호기심 많은 데이터 고양이 | 20% |
| StackFox | 영리한 코드 여우 | 20% |
| PromptPup | 낙천적인 프롬프트 강아지 | 20% |
| NullSlime | 느긋한 디지털 슬라임 | 20% |

부화한 종류는 성장기와 성체까지 유지됩니다. 미발견 종류가 남아 있는 동안
중복 부화가 5회 연속 발생하면 다음 알은 미발견 종류 중 하나로 확정됩니다.

등급은 부화할 때 처음 결정됩니다. 이후 `일반 → 희귀 → 영웅 → 전설`
순서로 유지되거나 올라가며 내려가지 않습니다.

| 현재 등급 | 유지 | 희귀 | 영웅 | 전설 |
|---|---:|---:|---:|---:|
| 일반 | 75.0% | 21.0% | 3.8% | 0.2% |
| 희귀 | 86.0% | - | 13.0% | 1.0% |
| 영웅 | 97.0% | - | - | 3.0% |
| 전설 | 100% | - | - | - |

천장이 없을 때 알에서 부화한 성체의 최종 분포는 일반 42.2%, 희귀 40.9%,
영웅 15.5%, 전설 1.4%입니다.

낮은 등급이 오래 이어지는 상황을 막기 위해 완성한 성체를 기준으로 다음을
보장합니다.

- 최대 3회 완료 여정 안에 희귀 이상
- 최대 7회 완료 여정 안에 영웅 이상
- 최대 16회 완료 여정 안에 전설

천장은 도감에서 남은 최대 완료 여정 수로 확인할 수 있습니다. 중간에 새 알로
다시 시작해도 기존 천장은 유지되지만 앞당겨지지는 않습니다.

## 도감

1세대 도감은 5종 × 유년기·성장기·성체 × 4등급 외형, 총 60개로 구성됩니다. 등급이 없는
알은 도감 외형 수에 포함하지 않습니다.

진화에서 해당 단계와 등급으로 직접 본 외형만 **만남**으로 기록됩니다.
예를 들어 일반 유년기에서 희귀 성장기로 진화하면 일반 유년기와 희귀 성장기만
등록되며, 만나지 않은 희귀 유년기는 잠긴 상태로 남습니다.

메뉴의 격자 버튼 또는 **설정 → Tokeni → 펫 도감 열기**에서 다음을
확인할 수 있습니다.

- 5종의 발견 여부와 부화 만남 횟수
- 60개 외형의 해금 상태
- 실제로 만난 단계·등급
- 완료한 여정, 최고 등급, 최고 친밀도
- 각 등급 천장까지 남은 최대 완료 여정

## 새 알과 여정 마치기

성체가 되면 현재 모습과 계속 함께하며 친밀도를 올리거나, 에너지 800을 사용해
여정을 마치고 새 펫을 즉시 부화할 수 있습니다. 800은 새 알 비용 300과 부화
비용 500의 합계입니다. 완료한 펫의 최종 등급과 친밀도를 기록하고 천장을
갱신한 뒤, 새 펫의 종류와 첫 등급을 한 번에 공개합니다.

성체 이전에도 에너지 300을 사용해 새 알을 받을 수 있습니다.

- 해금한 도감과 기존 천장은 유지됩니다.
- 사용하지 않은 행동 에너지는 유지됩니다.
- 중도 이별은 완료 여정이나 천장 진척으로 계산하지 않습니다.
- 같은 날 이미 사용한 에너지를 새 알에 다시 쓸 수 없습니다.

완료한 성체는 도감의 **완료한 펫**에 계속 보관됩니다. 원하는 펫을
**함께 지내기**로 꺼내 메뉴바, 설정 미리보기와 화면 위 펫에 표시할 수 있고,
**보관하기**를 누르면 현재 성장 중인 펫으로 돌아옵니다. 완료 펫은 전시용으로
고정되며 다시 진화하거나 여정을 완료할 수 없습니다. 행동 에너지는 현재
여정에 쌓이고, 함께 지내는 완료 펫의 동행 특성이 발동합니다.

## 특성과 패시브

함께 지내는 펫의 동행 특성 하나가 발동합니다. 완료한 보관 펫은 별도의 패시브
슬롯에 편성할 수 있으며, 슬롯은 기본 1칸에서 실제 도감 형태 30·60·90·120개를
만날 때마다 한 칸씩 영구 해금됩니다. 같은 종은 한 슬롯에만 배치할 수 있습니다.

1세대의 ByteBot과 CacheCat은 동행형, StackFox·PromptPup·NullSlime은
패시브형입니다. 등급별 수치, 처리 순서, 개인정보 및 새 세대 추가 규칙은
[Tokeni 펫 시스템 정책](companion-policy.ko.md)을 기준으로 합니다.

## 별조각과 출석 보상

별조각은 성장 에너지와 분리된 보상 재화입니다. 성장 에너지는 계속 확인된
토큰 증가분에서만 만들어지며, 출석이나 앱 활동 시간은 성장 에너지를 만들지
않습니다.

| 획득 조건 | 별조각 |
|---|---:|
| 그날 첫 검증 성장 시 자동 활동 출석 | 10 |
| 그날 첫 검증 성장 에너지 획득 | 5 |
| 같은 주 누적 3일 / 5일 / 7일 | 10 / 20 / 30 |
| 같은 달 누적 20일 | 50 |
| 새로운 펫 종류 최초 발견 | 20 |
| 희귀 / 영웅 / 전설 최초 만남 | 10 / 25 / 50 |
| 성체 여정 완료 | 25 |
| 도감 10개 / 30개 / 60개 해금 | 20 / 50 / 100 |
| 새 안정 버전 첫 실행 | 20 |

별도의 출석 버튼은 없습니다. 첫 검증 성장 관측이 반영될 때 활동 출석도
자동 처리됩니다. 출석은 연속 출석이 아니라 주간·월간 누적 방식입니다. 하루를 놓쳐도 이미
쌓인 횟수는 초기화되지 않습니다. 한 로컬 날짜에는 한 번만 받을 수 있고,
시스템 날짜가 마지막 출석일보다 과거로 이동하면 날짜가 정상화될 때까지
수령할 수 없습니다.

업데이트 전에 이미 달성한 펫 발견, 완료 여정과 도감 단계는 보상 상태를 처음
불러올 때 한 번만 소급 지급합니다. 이후 같은 기록을 다시 읽어도 중복
지급하지 않습니다.

### 별조각 꾸미기

펫 도감에서 별조각으로 다음 꾸미기를 영구 해금할 수 있습니다.

| 슬롯 | 꾸미기 | 가격 |
|---|---|---:|
| 오라 | 반짝임 오라 | 별조각 60개 |
| 오라 | 픽셀 하트 | 별조각 80개 |
| 머리 | 개발자 헤드폰 | 별조각 100개 |
| 머리 | 별 왕관 | 별조각 120개 |
| 머리 | 마법사 모자 | 별조각 140개 |
| 배경 | 터미널 나이트 | 별조각 160개 |
| 오라 | 밤하늘 링 | 별조각 200개 |
| 배경 | 구름 정원 | 별조각 220개 |

구매한 꾸미기는 자유롭게 착용하거나 해제할 수 있고 머리·오라·배경에서 하나씩
동시에 사용할 수 있습니다. 선택한 꾸미기는 메뉴 팝오버, 도감의 현재 펫,
설정 미리보기와 화면 위 펫에 함께 표시됩니다.
꾸미기 크기는 설정에서 선택한 펫의 작게·보통·크게 크기에 맞춰 함께 조정됩니다.
구매 전 현재 조합과 구매 후 모습을 나란히 미리 볼 수 있으며, 부족한 별조각
수와 확정적인 획득 경로를 표시합니다. 각 장식은 고유 움직임을 가지고
애니메이션 강도는 끔·잔잔하게·풍부하게 중 선택합니다. 밝은 배경에서는 오라
색상 대비를 자동 보정합니다.
꾸미기는 시각 효과일 뿐 성장 에너지, 등급, 진화 확률과 보장에는 영향을 주지
않습니다.

등급 차이는 종별 몸체 색과 원본 리소스에 포함된 몸체 형태로 표현합니다.
렌더러는 등급을 위해 펫 바깥에 원·오라·파티클·배경을 추가하지 않으며,
이 시각 레이어는 착용한 오라·배경 꾸미기 전용으로 유지됩니다.
현재는 획득 상태 필터를 우선 표시하고 세대가 하나일 때 세대 필터를 숨깁니다.
패시브 편성은 고급 항목에서 펼칠 수 있습니다. 완료한 패시브 펫은 완료 펫
카드에서 해금된 슬롯에 바로 배치할 수 있습니다. 보장 현황은 가장 가까운
보장 하나만 요약합니다.

## 메뉴바와 화면 위 표시

메뉴바 단색 상태 아이콘에는 알 부화 또는 유년기·성장기 단계 진화에 필요한 행동
에너지가 모였을 때 빨간 뱃지가 표시됩니다. 성체 여정 완료는 별도 선택이므로
이 뱃지에 포함하지 않습니다.

**설정 → Tokeni → 화면 위에 펫 표시**에서는 펫을 투명한 플로팅 패널로
표시할 수 있습니다. 표시 크기, 위치 잠금과 클릭 통과를 선택할 수 있으며,
드래그한 위치는 로컬 설정에 저장됩니다. 펫이 화면 밖에 있거나 모니터 구성이
바뀐 경우 **펫 위치 초기화**로 현재 화면 오른쪽 위에 되돌릴 수 있습니다.
클릭 통과를 끈 상태에서 펫을 클릭하면 토닥임 동작과 좌우 점프로 반응합니다.
클릭 통과를 켜면 아래 앱이 입력을 받으므로 토닥임과 이동은 사용할 수 없습니다.

## 토큰을 반영하지 못하는 경우

Tokeni Bar는 값의 범위와 초기화 시점을 확인할 수 있는 토큰만 성장에 씁니다.
데이터가 없거나 오래되었거나 파서가 현재 CLI 형식과 맞지 않으면 임의의 성장량을
만들지 않습니다.

- Codex와 Claude의 완전한 일일 누적은 확인된 사용 날짜에 반영합니다. 최대
  3일 늦게 확인된 합계의 에너지는 확인된 날 지급합니다.
- Gemini와 Grok의 세션 누적, OpenCode의 전체 누적은 첫 관측을 기준선으로 삼고
  이후 증가분부터 반영합니다.
- 앱이 날짜 경계 동안 꺼져 있어 어느 날의 사용인지 알 수 없는 세션·전체 누적은
  소급 추정하지 않습니다.
- 비정상적으로 큰 증가는 다음 관측에서 다시 확인한 뒤 반영합니다.

상세한 집계와 비용 표시 규칙은 [사용량 표시 안내](usage.ko.md)를 참고하세요.

## 저장과 개인정보

종류, 단계, 등급, 에너지, 친밀도, 도감, 보상과 화면 위 펫 설정은 Mac에만
저장됩니다. 집계 사용 기록은 30일 동안 유지되며, 손상된 진행 데이터는 보관된
로컬 복구본으로 자동 복구를 시도합니다.

펫 상태에는 제공자 이름이나 원본 토큰 합계를 넣지 않습니다. 프롬프트, 응답,
인증 토큰, 쿠키 또는 계정 비밀정보도 저장하지 않으며 분석 도구나 서버
텔레메트리는 없습니다.

별도의 게임 서버나 계정이 없는 로컬 앱이므로 진행 데이터는 강한 부정행위
방지 수단이 아닙니다. 일관성 검사와 복구는 우발적인 손상과 중복 반영을 줄이기
위한 것이며, 기기 소유자가 로컬 데이터를 의도적으로 수정하는 것까지 보장하지
않습니다.
