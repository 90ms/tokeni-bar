# Tokeni 펫 성장과 도감

**한국어** | [English](bytebot.md)

Tokeni 펫은 Tokeni Bar가 확인한 에이전트 토큰 사용량으로 성장하는 로컬 픽셀
동반자입니다. 별도의 게임 계정이나 서버가 없으며 펫 상태에는 제공자 이름,
원본 토큰 합계, 프롬프트 또는 응답 내용을 넣지 않습니다.

## 핵심 흐름

1. 검증된 누적 토큰 증가가 행동 에너지로 바뀝니다.
2. 사용자가 직접 알을 부화하고 유년기·성장기·성체로 키웁니다.
3. 부화한 펫에 이름을 붙이고 성격, 친밀도와 추억을 쌓습니다.
4. 성체 여정을 마치면 그 개체를 보관하고 새로운 알을 만납니다.
5. 다섯 종의 기본색·프리즘 모습을 모으고 별조각으로 꾸밉니다.

배고픔, 질병, 죽음이나 접속하지 않은 날의 불이익은 없습니다. 쉬는 동안에는
펫도 잠들어 기다립니다.

## 성장 에너지

여러 제공자의 확인된 토큰 증가분을 중복 없이 합산한 값을 `T`라고 할 때:

```text
성장 에너지 = floor(T / 100,000)
```

10만 개 미만의 나머지 토큰과 사용하지 않은 행동 에너지는 날짜를 넘어
유지됩니다. 성장 에너지는 검증된 누적 토큰 관측으로만 만들어집니다. 활동
시간은 동작을 바꿀 수 있지만 성장량을 만들지 않습니다.

| 행동 | 소비 에너지 |
|---|---:|
| 알 부화 | 500 |
| 성장기로 진화 | 800 |
| 성체로 진화 | 1,400 |
| 성체 여정 완료 후 새 펫 부화 | 800 |
| 성체 전 새 알 받기 | 300 |

에너지가 충분해도 자동으로 진화하지 않습니다. 성장 순간과 새 친구를 만나는
시점은 사용자가 선택합니다.

## 다섯 종과 시각 변종

현재 등록된 펫은 ByteBot, CacheCat, StackFox, PromptPup, NullSlime 다섯
종이며 기본 부화 확률은 같습니다. 미발견 종이 남아 있을 때 중복 부화가
5회 연속 발생하면 다음 알은 미발견 종 중 하나로 확정됩니다.

일반·희귀·영웅·전설의 서열형 등급은 사용하지 않습니다. 신규 펫은 다음 중 한
모습으로 부화하며, 모습은 여정 내내 바뀌지 않습니다.

| 변종 | 기본 확률 | 성능 |
|---|---:|---|
| 기본색 | 92% | 동일 |
| 프리즘 | 8% | 동일 |

기본색이 11회 연속 나오면 12번째 부화는 프리즘으로 보장됩니다. 프리즘은
희귀한 시각적 발견일 뿐 성장 속도, 보상과 확률을 높이지 않습니다.

업데이트 전 희귀·영웅 외형은 각각 **레거시 블루**, **레거시 바이올렛** 바디
컬러로 다시 구매할 수 있습니다. 전설 외형은 새 체계의 프리즘에 대응합니다.
개편 전 보유 자산은 외형을 억지로 합치는 대신 아래 초기화·환급 절차로
정산합니다.

변종은 문자열 ID와 레지스트리로 정의되므로 이후 새 변종을 추가해도 저장
스키마와 공용 UI에 제공자별 분기를 넣지 않습니다.

## 도감과 성장 앨범

메인 도감 목표는 `5종 × 기본색·프리즘`, 총 10개입니다. 유년기·성장기·성체
스프라이트는 별도의 수집 칸을 부풀리지 않고 해당 종·변종의 성장 앨범으로
기록됩니다.

도감에서는 다음을 확인할 수 있습니다.

- 다섯 종의 발견 상태
- 종별 기본색·프리즘 발견 상태
- 각 변종에서 실제로 본 성장 단계
- 가장 가까운 미발견 종 또는 프리즘 보장
- 완료한 개체와 그 개체의 이름·성격·친밀도·추억

## 이름, 성격, 친밀도와 추억

부화한 개체에는 차분함, 호기심, 장난꾸러기, 몽상가, 씩씩함 중 하나의 성격이
생기며 사용자가 이름을 붙일 수 있습니다. 이름과 성격은 능력치가 아니라 표시와
관계 표현을 위한 정보입니다.

성체 이후 함께 확인한 성장 에너지는 친밀도에 반영됩니다. 친밀도 단계는
0·50·150·400·800 에너지에서 1~5단계로 올라갑니다. 친밀도는 내려가지 않으며
성장·보상 배수를 만들지 않습니다.

추억에는 다음과 같은 콘텐츠 없는 사건만 기록됩니다.

- 처음 부화한 날
- 진화한 날
- 처음 토닥인 날
- 새 친밀도 단계에 도달한 날
- 성체 여정을 함께 마친 날

완료한 펫은 이름, 성격, 최종 모습과 친밀도를 유지한 채 보관됩니다. 원하는
펫을 다시 화면 위 동반자로 선택해도 행동 에너지는 현재 육성 여정에 쌓입니다.
동행 펫이나 보관 펫은 성장·비용·확률 보너스를 제공하지 않습니다.

## 별조각과 꾸미기

별조각은 성장 에너지와 분리된 꾸미기 재화입니다.

| 획득 조건 | 별조각 |
|---|---:|
| 그날 첫 검증 성장 시 자동 활동 출석 | 10 |
| 그날 첫 검증 성장 에너지 획득 | 5 |
| 주간 3일 / 5일 / 7일 활동 | 10 / 20 / 30 |
| 월간 20일 활동 | 50 |
| 새로운 펫 종류 최초 발견 | 20 |
| 프리즘 최초 발견 | 50 |
| 성체 여정 완료 | 25 |
| 도감 5개 / 10개 발견 | 20 / 100 |
| 새 안정 버전 첫 실행 | 20 |

꾸미기 슬롯은 머리, 오라, 배경, 바디 컬러입니다. 구매한 꾸미기는 메뉴 팝오버,
펫 도감, 설정 미리보기와 화면 위 펫에 함께 적용됩니다.

| 슬롯 | 꾸미기 | 가격 |
|---|---|---:|
| 오라 | 반짝임 오라 / 픽셀 하트 | 60 / 80 |
| 바디 컬러 | 레거시 블루 / 레거시 바이올렛 | 90 / 110 |
| 머리 | 개발자 헤드폰 / 별 왕관 / 마법사 모자 | 100 / 120 / 140 |
| 배경 | 터미널 나이트 / 구름 정원 | 160 / 220 |
| 오라 | 밤하늘 링 | 200 |

꾸미기는 구매 전에 현재 모습과 적용 후 모습을 비교할 수 있습니다. 모든
꾸미기와 바디 컬러는 시각 효과이며 성장, 보상, 변종 확률에 영향을 주지
않습니다.

## 펫 자산 초기화와 환급

대규모 펫 정책 변경은 자동으로 자산을 삭제하지 않습니다. 초기화할 펫, 도감
또는 꾸미기가 있으면 메뉴 팝오버, 펫 도감과
**설정 → Tokeni → 데이터 및 이전**에 예상 환급 카드가 표시됩니다.

| 자산 | 환급 |
|---|---:|
| 알 | 에너지 0 |
| 유년기 | 에너지 500 |
| 성장기 | 에너지 1,300 |
| 성체 | 에너지 2,700 |
| 완료한 펫 | 마리당 에너지 2,700 |
| 보유 꾸미기 | 등록 가격만큼 별조각 |

도감 기록 자체에는 별도 재화를 지급하지 않지만 초기화 대상 개수를 견적에
표시합니다. 친밀도는 성장 에너지와 동시에 누적된 값이고 여정 완료 비용은
새 부화와 보상을 이미 제공했으므로 중복 환급하지 않습니다.

확정 전에는 기존 펫 상태를 읽기 전용으로 유지합니다. 확정하면 펫, 이름,
성격, 친밀도, 추억, 도감, 보장, 기존 특성 상태와 꾸미기 보유·착용 상태를
초기화합니다. 사용하지 않은 에너지와 별조각, 출석, 검증 성장 정산 기록은
그대로 유지합니다.

앱은 원본 상태와 확정 잔액을 담은 로컬 복구 기록을 먼저 저장합니다. 각 이전
ID는 한 번만 처리하며 저장 도중 종료되면 같은 확정 잔액으로 이어서 처리합니다.
환급 에너지는 일반 안전 상한과 분리된 이전 잔액에 보관되며 행동할 때 먼저
사용됩니다. 완료 영수증은 설정에서 다시 확인할 수 있고 환급 기한은 없습니다.

## 동작과 화면 위 펫

펫은 작업 중·최근 활동·휴식·쿼터 경고·토닥임에 맞춰 반응합니다. 이 상태는
연출이며 네트워크 응답 내용이나 작업 내용을 읽어 만든 것이 아닙니다.

**설정 → Tokeni → 화면 위에 펫 표시**에서 크기, 위치 잠금과 클릭 통과를
선택할 수 있습니다. 동작 줄이기, 애니메이션 끄기와 저전력 모드를 존중합니다.

## 저장과 개인정보

종, 단계, 변종, 이름, 성격, 에너지, 친밀도, 추억, 도감과 꾸미기는 Mac에만
저장됩니다. 추억에는 제공자 이름, 토큰 합계, 프롬프트, 응답 또는 인증정보가
들어가지 않습니다. 분석 도구나 원격 게임 서버도 사용하지 않습니다.

자산 이전 저널도 Mac에만 저장되며 이전 ID, 환급 견적, 원본 펫·보상 상태,
확정 상태와 영수증만 포함합니다. 제공자 이름, 원본 토큰 합계, 작업 내용이나
인증정보는 포함하지 않습니다.

확인할 수 없거나 오래된 토큰 값으로 성장량을 만들지 않습니다. 상세 집계
규칙은 [사용량 표시 안내](usage.ko.md)를 참고하세요.
