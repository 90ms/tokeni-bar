# Tokeni 펫 시스템 정책

**한국어** | [English](companion-policy.md)

- 정책 버전: 2.4.0
- 갱신일: 2026-08-05
- 상태: 구현됨

이 문서는 무제한 레벨, 진화, 알 경제, 보유 펫, 도감, 변이 연구소, 보상과
개인정보 기준을 정의한다.

## 1. 불변 규칙

- 성장 XP는 검증된 누적 토큰 증가에서만 계산한다.
- 활동 시간은 동작을 바꿀 수 있지만 XP를 만들지 않는다.
- 확인할 수 없는 사용량은 추정하지 않는다.
- 종, 변종, 성격, 알과 꾸미기는 성장·비용·보상 배수를 만들지 않는다.
- 변이는 시각 요소이며 성장 XP, 부화 확률, 능력치와 판매가에 영향을 주지 않는다.
- 시간제 부스터만 검증된 기본 XP에 명시된 배율을 적용한다.
- 배고픔, 질병, 죽음, 연속 접속 손실과 기간 한정 FOMO를 사용하지 않는다.
- 펫 상태에는 제공자 이름, 원본 토큰 합계, 프롬프트, 응답 또는 인증정보를
  저장하지 않는다.

## 2. 성장과 진화

표준 변환식은 검증 토큰 2만 5천 개당 성장 XP 1이다. 레벨은 XP에서 파생하며
별도로 저장하지 않고 상한을 두지 않는다.

```text
다음 레벨 XP = min(2 + floor((현재 레벨 - 1) / 10), 15)
```

유년기는 레벨 1, 성장기는 레벨 10, 성체는 레벨 25에 대응한다. 진화는 사용자가
직접 실행하며 XP를 소비하지 않는다. 레벨 조건을 넘겨도 진화를 실행하기 전에는
현재 외형을 유지한다. 레벨 25 이후에도 같은 펫의 성장은 계속된다.
레벨 30부터 10레벨마다 별조각 10개를 계정 재화로 지급한다.

## 3. 보유 펫과 알

최초 상태는 판매 불가능한 스타터 알 하나를 가진다. 기존 활성 펫을 가져오는
마이그레이션에는 판매 불가능한 귀환 선물 알 하나를 지급한다. 부화한 펫은 UUID로 구분하고
한 펫만 성장 대상으로 선택한다. 새 부화는 현재 펫을 삭제하거나 완료하지 않고
보유 목록에 추가한다. 성장 대상을 바꿀 때 XP, 폼, 이름, 성격과 추억을 보존한다.

알 정의에는 다음만 포함한다.

- 안정적인 문자열 ID
- 구매·판매 가격
- 해금 조건
- 종 후보와 변종 규칙
- 미발견 종 또는 프리즘 보장 여부
- 판매 가능 여부

현행 상점은 최고 펫 레벨 5에서 수수께끼 알, 서로 다른 3종 발견에서 발견 알을
해금한다. 가격은 각각 별조각 90·180이며 판매가는 30·60이다. 스타터 알은
판매할 수 없다. 실제 결제, 기간 한정 판매와 사용자 간 거래를 사용하지 않는다.

성장 중인 펫은 보낼 수 없다. 비활성 기본색 펫은 별조각 30, 프리즘 펫은 60을
받고 새 주인에게 보낼 수 있다. 레벨은 판매가를 높이지 않으며 도감 기록은
판매 후에도 유지된다.

같은 종의 비활성 보관 펫 정확히 3마리는 변이 연구소에서 합성할 수 있다. 합성에
사용한 세 개체는 소비되고, 해당 종의 변이 하나가 도감에 기록된다. 현재 펫은
합성 재료가 될 수 없다.

## 4. 도감과 보장

현재 다섯 종의 기본 확률은 동일하다. 미발견 종이 남은 동안 중복 부화 5회 뒤
다음 일반 부화는 미발견 종에서 고른다. 기본색 92%, 프리즘 8%이며 기본색 11회
뒤 12번째 일반 부화는 프리즘이다.

메인 도감은 `5종 × 기본색·프리즘` 10개다. 성장 폼은 분모를 늘리지 않고 성장
앨범에 남긴다. 다섯 종 발견은 발견 알, 5개와 10개 조합 발견은 각각 프리즘
알을 한 번 지급한다. 발견 알은 미발견 종을, 프리즘 알은 프리즘을 보장한다.

변이 도감은 종마다 네온·그림자·크리스탈·글리치·오로라 5개씩, 총 25개다. 따라서
전체 수집 분모는 변종 10개와 변이 25개를 합친 35개다. 전역 합성 횟수가 3의
배수일 때 선택한 종에 미발견 변이가 남아 있으면 그중 하나를 보장한다. 이미
발견한 변이가 다시 나오면 공명 단계만 강화하며, 변이 발견은 해당 항목마다
별조각 30개를 한 번 지급한다. 변이 항목은 종·변종 도감 마일스톤이나 특별 알
마일스톤의 개수에 포함하지 않는다.

## 5. 레벨 보상과 꾸미기

각 펫은 레벨 5·10·20·25를 처음 달성할 때 각각 2배 부스터, 3배 부스터,
반딧불 오라, 5배 부스터와 궤도 오라를 받는다. 이전 친밀도 보상을 받은 개체는
대응 레벨 보상을 중복 수령하지 않는다.

별조각은 자동 활동 출석, 검증 성장, 종·변종 발견, 도감 마일스톤과 안정 버전
선물에서 얻는다. 알, 부스터와 시각 꾸미기에 사용한다. 구매 가격보다 판매 가격이
항상 낮아야 하며 XP를 반복 재화로 바꾸는 구조를 만들지 않는다.

## 6. 개체 정체성과 추억

각 펫은 UUID, 종, 변종, 폼, XP, 로컬 이름, 등록된 성격 ID와 생성 시각을 가진다.
개체에는 선택적으로 장착한 변이 ID가 기록되며, 발견 변이와 공명 단계는 계정
도감 기록으로 관리한다.
추억은 펫마다 최근 40개, 계정 전체 최대 2,000개의 콘텐츠 없는 이벤트만 보관한다. 기존 부화·진화·토닥임·
친밀도·여정 완료 기록은 이전 후에도 유지한다. 추억에 작업 내용이나 원본 사용량
숫자를 넣지 않는다.

## 7. 저장과 거래 안전성

알은 UUID와 안정적인 난수 시드를 가진다. 구매와 판매는 먼저 거래 저널에 기록하고
트랜잭션 UUID로 펫 상태와 재화의 중복 처리를 막는다. 부화는 알 ID와 시드로 결과를 고정한다. 결과와 보장 카운터를
상태에 반영한 뒤 연출을 표시해 앱이 중간에 종료되어도 결과가 다시 추첨되거나
보상이 중복되지 않게 한다.

저장 스키마 v10은 활성 펫, 비활성 보유 펫, 획득 알 출처, 알, 성장 XP, 최고 레벨,
도감 알 마일스톤, 변이 기록, 합성 횟수, 장착 변이, 변이 보상 키와 처리한 알
트랜잭션을 저장한다. 새 필드는 선택적으로 읽어 기존 v10 파일도 계속 읽을 수 있다.
손상된 데이터는 복구본을 사용하고
복구할 수 없으면 사용 불가 상태로 둔다.

제공자 JSONL은 파일 전체나 전체 이벤트 배열을 만들지 않고 한 줄씩 처리한다.
펫 스프라이트는 현재 필요한 시트만 불러오며 시트·프레임 캐시에 비용 제한을
둔다. 오버레이를 숨기면 호스팅 뷰와 애니메이션 작업도 함께 해제한다.

## 8. 이전과 호환성

- v2~v9 상태는 전용 읽기 디코더로 v10에 올린다.
- 유년기는 최소 레벨 1, 성장기는 10, 성체는 25를 보장한다.
- 기존 행동 에너지와 성체 친밀도 중 큰 진행도를 새 XP에 더하고 중복 행동력
  잔액은 제거한다.
- 완료 펫은 판매 가능한 비활성 보유 펫으로 옮긴다.
- 기존 활성 펫에는 귀환 선물 알 하나를 지급한다. 활성 펫이 없는 기존 알 상태는
  스타터 알을 가진 상태로 복구한다.
- 기존 펫은 이전 당시 이미 지난 레벨 보상을 소급해서 받지 않지만 다음 신규
  마일스톤부터 정상적으로 받는다.
- 종·변종 보장, 이름, 성격, 추억, 별조각, 꾸미기와 부스터를 유지한다.
- 이전 파일에 변이 기록, 합성 횟수, 장착 변이와 변이 보상 키가 없으면 각각 빈
  기록, 0회, 없음과 빈 키로 시작한다. 기존 펫과 변종 도감은 그대로 유지한다.

## 9. 새 콘텐츠 추가 절차

1. 종, 변종, 변이, 진화 또는 알의 안정적인 ID를 등록한다.
2. 신규 폼이면 모든 필요한 스프라이트와 manifest를 추가한다.
3. 알의 가격, 판매가, 확률, 보장과 해금 조건을 명시한다.
4. 도감 분모와 특별 알 마일스톤 포함 여부를 명시한다.
5. 변이 시각 효과와 중복 합성·보장 규칙을 명시하고 저장 왕복, 이전, 중복 거래와
   확률 fixture 테스트를 추가한다.
6. 한국어·영어 문자열과 문서를 함께 갱신한다.

## 10. 2.3.0 개편 기록

- 소비형 성장 단계를 무제한 레벨과 레벨 진화로 교체했다.
- 초기 성장 속도를 높이고 레벨당 XP를 최대 15로 제한했다.
- 성체 완료와 행동 에너지 기반 새 여정 시작을 제거했다.
- 스타터 알, 알 보관함, 별조각 상점, 알 판매와 특별 알 보상을 추가했다.
- 현재·완료 펫을 전환 가능한 보유 펫 구조로 통합했다.
- 친밀도 보상을 레벨 5·10·20·25 보상으로 옮겼다.
- 레벨 30부터 10레벨마다 별조각 10개를 반복 지급한다.

## 11. 2.4.0 변이 연구소

- 같은 종의 비활성 중복 펫 3마리를 소비해 시각 변이를 발견한다.
- 종마다 5개씩, 전체 25개의 변이 도감 항목과 장착 슬롯을 추가했다.
- 합성 3회마다 미발견 변이를 보장하고, 첫 발견마다 별조각 30개를 지급한다.
- 변이는 성장과 경제에 영향을 주지 않으며 반복 발견은 공명 단계만 강화한다.
