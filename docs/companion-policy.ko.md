# Tokeni 펫 시스템 정책

**한국어** | [English](companion-policy.md)

- 정책 버전: 2.2.0
- 갱신일: 2026-07-31
- 상태: 구현됨

이 문서는 펫 성장, 변종, 개체 정체성, 도감, 보상과 꾸미기의 기준 문서다.

## 1. 불변 규칙

- 성장은 검증된 누적 토큰 증가에서만 계산한다.
- 활동 시간은 동작을 바꿀 수 있지만 성장량을 만들지 않는다.
- 확인할 수 없는 사용량은 추정하지 않는다.
- 펫 선택, 성격, 변종과 꾸미기는 성장·비용·보상·확률 배수를 만들지 않는다.
- 시간제 부스터만 검증된 기본 행동 에너지에 명시된 배율을 적용한다.
- 배고픔, 질병, 죽음, 연속 접속 손실과 기간 한정 FOMO를 사용하지 않는다.
- 펫 상태에는 제공자 이름, 원본 토큰 합계, 프롬프트, 응답 또는 인증정보를
  저장하지 않는다.

## 2. 확장 가능한 등록 구조

종과 변종은 공용 레지스트리를 통해 등록한다. UI에서 종·변종별 switch를
추가하지 않는다.

변종 정의에는 다음만 포함한다.

- 안정적인 문자열 ID
- 사용할 기존 스프라이트 팔레트
- 메인 도감 포함 여부
- 특별한 시각 변종 여부

변종에는 순위나 전투력 값이 없다. 신규 변종을 추가해도 기존 저장 데이터와
알 수 없는 ID를 안전하게 다룰 수 있어야 한다.

## 3. 성장과 부화

표준 변환식은 `floor(검증 토큰 / 50,000)`이다. 행동 비용은 부화 500,
성장기 800, 성체 1,400, 완료 후 새 부화 800, 중도 새 알 300이다.

현재 다섯 종의 기본 확률은 동일하다. 미발견 종이 남은 동안 중복 부화 5회
뒤에는 다음 부화를 미발견 종에서 고른다.

신규 부화의 변종 확률은 기본색 92%, 프리즘 8%다. 기본색 11회 뒤 12번째는
프리즘이다. 변종은 부화 시 결정되어 진화 중 바뀌지 않는다.

기존 등급 기반 확률, 성체 등급 천장, 행운 재판정과 비용 할인은 신규 규칙에
적용하지 않는다.

## 4. 도감

메인 완성도는 `등록 종 × 수집 대상 변종`으로 계산한다. 1세대는 5종 ×
기본색·프리즘으로 10개다.

성장 단계는 별도 완성도 칸이 아니라 해당 종·변종의 여정 앨범이다. 레거시
컬러는 신규 상점 꾸미기로 제공하지만 메인 도감 분모를 늘리지 않는다.

보장은 다음 두 개만 제공한다.

- 미발견 종 보장
- 프리즘 보장

UI는 두 보장 중 가까운 하나를 먼저 보여준다.

## 5. 개체 정체성과 추억

현재 개체와 완료 개체는 UUID로 구분한다. 개체 데이터는 다음을 가질 수 있다.

- 최대 24자의 로컬 이름
- 등록된 성격 ID
- 종, 변종과 성장 단계
- 친밀도 에너지와 단계
- 생성·완료 시각

성격은 표현 전용이며 능력치가 아니다. 친밀도 단계 기준은 0, 50, 150, 400,
800 에너지다.

각 세대에서 레벨 2는 2배 부스터, 레벨 3은 3배 부스터, 레벨 4는 반딧불
오라, 레벨 5는 5배 부스터와 궤도 오라를 한 번 지급한다. 부스터 추가분은
친밀도에 포함하지 않는다.

추억은 최대 400개의 구조화된 이벤트만 보관한다.

- 부화
- 진화
- 첫 토닥임
- 친밀도 단계
- 여정 완료

추억에는 작업 내용이나 사용량 숫자를 넣지 않는다.

## 6. 보상과 꾸미기

별조각은 성장 에너지와 분리한다. 보상원은 자동 활동 출석, 첫 검증 성장,
종·프리즘 발견, 변종 도감 5·10개, 완료 여정과 안정 버전 선물이다.

꾸미기 슬롯은 오라, 배경, 바디 컬러다. 한 슬롯에 하나만 선택하며
모든 꾸미기는 시각 효과다. 랜덤 유료 상자나 소멸 기한을 사용하지 않는다.

레거시 블루·바이올렛 바디 컬러는 신규 상점 자산으로 제공한다. 전설 외형은
프리즘의 시각 리소스로 사용할 수 있다. `레거시`는 현행 컬러 자산의 이름일
뿐 실행 중인 이전 정책을 뜻하지 않는다.

부스터는 보상 상태의 별도 소비 아이템이다. 2배·30분, 3배·20분, 5배·10분을
제공하며 가격은 각각 별조각 80·150·280개다. 한 번에 하나만 활성화하고
절대 종료 시각을 저장한다. 배율은 새로 검증된 기본 행동 에너지에만 적용하며
추가 에너지와 친밀도에는 재적용하지 않는다.

## 7. 이전과 호환성

- 펫 저장 스키마 v2~v7은 전용 읽기 디코더로 현재 상태에 올린다.
- 현재 스키마의 알 수 없는 JSON 필드는 무시하되 알 수 없는 enum 값으로 전체
  보상 파일이 초기화되지 않도록 ID 제거는 신중히 처리한다.
- 필드 추가처럼 자산을 없애지 않는 변경은 기본값을 사용해 자동 처리한다.
- 환급 견적, 자산 초기화, 이전 잔액, 복구 저널과 완료 영수증은 현행 기능이
  아니며 새 상태에 기록하지 않는다.
- 손상된 데이터는 복구본을 사용하고 복구할 수 없으면 사용 불가 상태로 둔다.
- 저장 호환 코드를 제거할 때는 지원하는 최소 직접 업그레이드 버전과 fixture
  테스트를 함께 변경한다.

## 8. 새 콘텐츠 추가 절차

1. 종 또는 변종의 안정적인 ID를 등록한다.
2. 모든 성장 단계의 스프라이트와 manifest를 추가한다.
3. 기본·축소·저전력·동작 줄이기 렌더링을 확인한다.
4. 새 도감 분모와 보장에 포함할지 명시한다.
5. 저장 왕복과 이전 버전 fixture 테스트를 추가한다.
6. 한국어·영어 문자열과 문서를 함께 갱신한다.

새 콘텐츠는 능력치 우위를 만들기보다 실루엣, 동작, 성격 표현과 꾸미기
호환성으로 차별화한다.

## 9. 2.2.0 정책 기록

- 행동 에너지 기준을 검증 토큰 5만 개당 1로 조정했다.
- 머리 꾸미기 슬롯을 제거하고 범용 오라·배경을 확장했다.
- 시간제 2배·3배·5배 부스터와 친밀도 단계 최초 보상을 추가했다.
- 환급·자산 초기화·이전 잔액·저널·영수증 정책을 현행 규칙에서 제거했다.
- 팝오버의 펫 카드를 접지 않고 항상 표시한다.

## 10. 2.0.0 개편 기록

- 일반·희귀·영웅·전설 서열과 진화 중 등급 상승을 제거했다.
- 기본색·프리즘 변종과 단일 프리즘 보장을 추가했다.
- 60칸 단계·등급 도감을 10개 종·변종 도감과 성장 앨범으로 바꿨다.
- 동행 특성·패시브의 성장·비용·확률·보상 효과를 비활성화했다.
- 이름, 성격, 5단계 친밀도와 개인정보 없는 추억을 추가했다.
- 레거시 등급 리소스를 변종과 바디 컬러 꾸미기로 재사용했다.
