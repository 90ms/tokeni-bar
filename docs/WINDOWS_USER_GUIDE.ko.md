# Windows 사용 안내

## 설치와 실행

`Tokeni-Bar-Windows-<버전>-Setup.exe`로 현재 사용자용 앱을 설치합니다. 관리자 권한은
필요하지 않으며, 시작 메뉴의 **Tokeni Bar**에서 실행할 수 있습니다. ZIP 버전은
폴더 전체를 압축 해제한 뒤 `TokeniWindows.exe`를 실행합니다.

창을 닫으면 트레이에서 계속 실행합니다. 트레이 아이콘이나 실행 파일을 다시 열면
기존 창으로 돌아옵니다. 완전히 종료하려면 설정의 **Tokeni Bar 종료**를 선택하세요.

## 사용량과 기록

설정에서 사용할 제공자를 켜고, 해당 제공자의 CLI 또는 앱에서 로그인한 다음
**새로 고침**을 누르세요. 홈에는 현재 사용 가능 상태, 잔여량, 초기화 시각, 확인된
토큰과 비용이 표시됩니다. 없거나 오래된 데이터는 현재 수치로 표시하지 않습니다.

**사용량 → 기록**에서는 최근 24시간·7일·30일과 제공자를 선택할 수 있습니다.
그래프의 각 점은 해당 기록에서 가장 낮은 할당량 잔여 비율입니다. 표에는 기록 시각과
각 할당량, 당시 확인된 토큰 및 비용이 나옵니다. 누적 관측값이므로 행들을 합산한 값이
기간 사용량이나 기간 지출을 뜻하지는 않습니다.

## 펫

- **알 보관함**에서 알을 선택하고 **알 열기**를 누르면 새 펫을 만납니다.
- **컬렉션**에서 보유 펫을 선택해 이름을 저장하거나, 성장 대상 또는 대표 펫으로 지정합니다.
  성장 대상과 데스크톱에 표시할 대표 펫은 각각 선택할 수 있습니다.
- **상점과 보상**에서 출석 보상을 받고, 별 조각으로 알이나 꾸미기를 구매합니다.
  보유한 꾸미기는 장착 버튼으로 선택하고, 장착 중인 항목을 다시 선택하면 해제됩니다.
  알 구매에는 레벨 또는 수집 조건이 적용됩니다.
- 펫 성장은 확인된 누적 사용량을 기반으로 합니다. 출석이나 꾸미기 구매, 창 표시 시간으로
  성장량을 만들지 않습니다. 데스크톱 펫을 숨겨도 성장 처리는 계속됩니다.

**데스크톱 펫**을 켜면 다른 창 위에 펫을 표시합니다. **펫 이동 허용**을 켜고 드래그하면
위치를 옮길 수 있습니다. 이동을 끄면 마우스 입력이 아래 창으로 전달됩니다. 크기와
**움직임 줄이기**도 선택할 수 있으며 위치와 설정은 다음 실행에 유지됩니다.

## 설정과 업데이트

설정에서 Windows 자동 시작, 알림 테스트, 한국어·영어, 시스템·밝은·어두운 화면 모드를
선택합니다. 자동 시작은 현재 사용자에게만 적용됩니다.

**업데이트 확인**으로 새 릴리스를 조회합니다. **업데이트 자동 확인**은 기본적으로 꺼져
있으며, 켜면 주기적으로 확인합니다. 설치는 사용자가 설치 버튼을 누를 때 진행합니다.
앱과 설치 파일의 유효한 서명 및 동일 발행자를 검증하므로, 미서명 검증용 빌드와 ZIP으로
실행한 앱에서는 이 설치 경로를 사용할 수 없습니다.

업데이트 실행 검사에 실패하면 이전 앱 파일을 복구하고, 다음 실행에 결과를 표시합니다.
서명 계정 설정과 정식 배포 절차는 [Windows 패키징 안내](../packaging/windows/README.md)를
참고하세요. Windows 앱 제거 후에도 사용 기록과 펫·설정은 보존됩니다.
