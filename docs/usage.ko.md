# 사용량 표시와 성장 집계

**한국어** | [English](usage.md)

## 메뉴바 팝오버

팝오버의 제공자 카드는 첫 번째 핵심 쿼터, 남은 비율과 초기화 시각을 기본으로
표시합니다. **상세 보기**를 펼치면 나머지 쿼터 창, 토큰 합계, API 환산 참고
비용, 데이터 출처와 갱신 시각을 확인할 수 있습니다. 제공자가 많거나 상세
내용이 길어도 헤더와 하단 액션은 고정되고 가운데 영역만 스크롤됩니다.
사용량 카드가 먼저 나오고 펫 카드는 그 아래에 항상 표시됩니다. 축소 모드도
상세 정보 접근 경로를 없애지 않습니다.

하단의 **사용량 기록**은 30일 로컬 집계 창을 바로 열며, 설정과 종료는 오른쪽
아이콘으로 제공합니다.

## Tokeni 토큰 성장 집계

Tokeni 성장에는 제공자가 반환한 토큰 카운터의 **확인된 증가분**만 사용합니다.
활동 파일의 변경 시각은 작업·수면 애니메이션에만 쓰며 성장 XP를 만들지
않습니다.

여러 제공자의 확인된 증가분을 중복 지급 없이 합산해 토큰 600,000개마다
성장 XP 1을 지급합니다. XP로 바뀌지 않은 토큰은 날짜를 넘어
이월되며, 같은 누적값은 새로고침해도 한 번만 지급됩니다.

활성 부스터가 있으면 장부가 만든 기본 성장 XP에 2배·3배·5배 중 해당
배율을 적용합니다. 배율은 `GrowthEnergyAward`가 만들어진 확인 시각을
기준으로 결정하며, 이미 지급한 ID에는 다시 적용하지 않습니다. 부스터 추가 XP는
새 기본 지급으로 다시 취급하지 않고 다른 보너스 XP를 재증폭하지 않습니다.

제공자마다 카운터 범위가 달라 다음 규칙을 적용합니다.

- **일일 카운터**: Codex와 Claude의 확인된 날짜별 합계를 해당 날짜에 반영합니다.
- **세션 카운터**: Gemini와 Grok은 첫 관측값을 기준선으로 삼고 같은 세션의
  증가분만 반영합니다.
- **누적 카운터**: OpenCode는 첫 관측값을 기준선으로 삼고 이후 증가분만
  반영합니다.
- Codex 일일 카운터가 없으면 현재 세션 카운터를 같은 방식으로 사용합니다.

카운터가 줄거나 초기화되어도 지급한 성장 XP를 회수하지 않습니다. 앱이 꺼진 채
날짜가 바뀌어 어느 날의 사용인지 모르는 세션·누적 증가는 소급 추정하지 않습니다.
비정상적으로 큰 증가는 다음 관측에서 같은 값 이상이 확인된 뒤 지급합니다.
늦게 도착하는 완전한 일일 합계는 최근 3일까지 반영할 수 있습니다.

펫 도감의 합계와 목표는 오늘 사용일 장부를 기준으로 표시합니다. 제공자별
내역에는 각 제공자의 최근 확정 사용 날짜와 토큰을 별도로 표시합니다. 이전
날짜의 일일 합계가 오늘 처음 확인되면 **오늘 정산**으로 표시되고 그 성장 XP는
오늘 획득량에 더해집니다. 현재 신뢰할 수 있는 값이 없으면 0으로 간주하지 않고
**확인 대기**로 표시합니다.

앱은 로컬 진행 정보를 이용해 같은 사용량이 다시 반영되지 않도록 합니다.
저장 도중 앱이 종료되거나 데이터 일부가 손상된 경우에도 보관된 복구본을
우선 확인합니다.

레벨·진화·알 규칙은 [Tokeni 펫 성장과 알 도감](bytebot.ko.md)을 참고하세요.

## 리소스와 메모리 관리

Codex와 Claude의 로컬 JSONL은 파일 전체와 모든 이벤트를 한꺼번에 메모리에
올리지 않고 64KiB 청크에서 한 줄씩 해석합니다. 안전 제한을 넘는 파일과 심볼릭
링크는 사용하지 않으며, 읽는 도중 파일이 제한보다 커져도 해당 결과를 폐기합니다.

펫 스프라이트 manifest는 시작할 때 확인하지만 이미지 시트는 실제로 필요한
종·폼·변종만 지연 로딩합니다. 잘라낸 프레임은 원본 시트를 계속 붙잡지 않는
독립 이미지로 만들고, 시트 캐시는 8MiB, 프레임 캐시는 12MiB의 비용 제한을
사용합니다. 화면 위 펫을 끄면 패널의 SwiftUI 호스팅 뷰와 애니메이션 작업을
해제합니다.

작업 감지를 위한 제공자 디렉터리 확인은 10초 간격이며, 활동 중 펫 상태 저장은
날짜 변경을 제외하면 최대 1분에 한 번 수행합니다. macOS는 이미 해제된 메모리를
프로세스 재사용을 위해 RSS에 잠시 남길 수 있으므로 사용량이 즉시 내려가지 않을
수 있습니다. 로그 갱신이나 새 스프라이트 표시와 무관하게 메모리가 계속 증가하면
재현 절차와 진단 정보를 함께 보고해야 합니다.

## Codex 계정 토큰 사용량

Codex 계정 사용량은 설치된 Codex CLI의 기존 로그인을 재사용해 가져옵니다.
날짜별 합계는 해당 날짜가 끝난 뒤 도착할 수 있으며, 집계 지연 시간과 기준
시간대는 보장되지 않습니다.

팝오버에는 다음 값을 표시합니다.

- **최근 일일 사용량 (`yyyy-MM-dd`)**: 가장 최신 날짜의 유효한 버킷 합계
- **이번 달**: 현재 로컬 달력의 이번 달에 속하는 유효한 버킷 합계
- **누적**: 계정 서비스가 반환한 누적 합계

팝오버는 오늘 버킷 유무에 따라 **오늘 사용량 확정** 또는
**오늘 집계 대기 · yyyy-MM-dd까지 확정**을 표시합니다. 최신 확정 버킷이
최근 3일 안에 있으면 제공자와 사용 날짜를 키로 한 번만 성장 XP로 정산하며,
나중에 같은 버킷 값이 증가하면 증가분만 추가 정산합니다.

음수, 미래 날짜와 잘못된 값은 제외합니다. 유효한 일일 버킷이 없으면 임의의
값이나 0을 만들지 않습니다. Codex CLI 미발견, 로그인 필요, CLI 버전 미지원과
조회 실패도 서로 구분해 표시합니다.

### Codex CLI 연결 확인

메뉴바 앱은 터미널보다 제한된 `PATH`로 실행될 수 있습니다. Tokeni Bar는
일반적인 패키지 관리자와 사용자 설치 위치도 확인합니다. 그래도
**Codex CLI를 찾을 수 없음** 또는
**계정 토큰 조회 실패**가 표시되면 터미널에서 `codex`를 한 번 실행해 로그인과
CLI 업데이트를 확인한 뒤 Tokeni Bar를 다시 시작하세요. 인증 정보나 토큰은
Tokeni Bar가 복사하거나 별도로 저장하지 않습니다.

## Claude 메뉴바 쿼터

**설정 → 일반 → 메뉴바**에서 **선택한 제공자 잔여량**과 **Claude Code**를
고르면 **Claude 쿼터** 선택기가 나타납니다.

- **5시간**: 세션 쿼터
- **일주일**: 계정 주간 쿼터
- **Fable**: 모델 범위 주간 쿼터

기본값은 Fable이며 선택은 로컬에 저장됩니다. 현재 계정 응답에 선택한 창이
없으면 다른 쿼터로 바꾸어 표시하지 않고 사용 불가 상태로 둡니다.

### Claude 키체인 연결

Claude 계정 쿼터는 Claude Code가 macOS 키체인에 저장한 기존 OAuth 로그인을
재사용합니다. Tokeni Bar는 토큰을 복사하거나 별도로 저장하지 않습니다.

- 앱 시작과 자동 새로고침은 Claude Code 키체인 항목을 조회하지 않습니다.
  암호창을 열지 않고 로컬 Claude 세션 기록만 사용합니다.
- 최초 연결은 **설정 → 일반 → 제공자 → Claude Code 연결**에서 사용자가
  직접 시작합니다. 승인하면 현재 앱 실행 중에는 계정 쿼터도 갱신합니다.
- Tokeni Bar를 재시작하면 다시 로컬 전용 상태가 되며, 계정 쿼터가 필요할 때
  사용자가 연결을 다시 선택합니다.

잠금 해제만으로 Tokeni Bar가 대화형 인증을 시작하지는 않습니다. 연결이
필요한 상태에서도 확인할 수 없는 계정 쿼터를 만들지 않고 로컬 세션 사용량만
표시합니다.

설정의 연결 행은 **계정 사용량에 연결됨**, **로컬 사용량만 확인 중**,
**키체인 승인 필요**, **세션 만료**, **연결 상태 확인 불가**를 구분합니다.

## 사용량 알림

**설정 → 알림**은 사용량 알림, 갱신 알림, 시스템 상태 알림과 전달 설정으로
나뉩니다. 잔여량 부족, 쿼터 갱신 1시간 전, 월 예산, 제공자 연결 실패를
각각 켜고 끌 수 있습니다.

- 같은 새로고침에서 여러 제공자 경고가 발생하면 하나의 알림으로 묶습니다.
- 같은 쿼터가 곧 갱신되면 잔여량 부족 알림과 갱신 알림을 중복 발송하지
  않습니다.
- 조용한 시간에는 배너를 유지하고 소리만 끕니다.
- 15분 이상 간격의 실제 잔여량 감소가 관측된 경우에만 갱신 전 소진 가능성을
  덧붙입니다. 근거가 부족하면 예측하지 않습니다.
- 알림을 누르면 설정의 알림 탭이 열립니다. 최근 발송 또는 제외 사유는
  기본적으로 접힌 **최근 알림 판단**에서 확인할 수 있습니다.

제공자가 갱신 시각을 반환하지 않으면 갱신 알림을 만들지 않습니다. 같은
제공자·쿼터·갱신 주기에는 한 번만 발송합니다.

## 비용 추정, 환율과 기록

비용은 확인 가능한 토큰을 공개 API 단가로 사용했을 때의 참고 추정액이며 API
청구서나 구독 청구액이 아닙니다.

Codex 계정 활동에는 과거 모델, 입력·출력, 캐시와 추론 토큰 구분이 없으므로
정확한 API 비용을 계산할 수 없습니다. 일일·월간·누적 비용은 앱에 포함된
버전 관리 참고 프로필을 사용하며 토큰 합계가 기준 데이터입니다.

- USD/KRW는 [Frankfurter](https://frankfurter.dev/)의 ECB 제공자를 통해
  한국 시간 기준 하루 한 번 확인합니다.
- 모델 가격표는 하루 한 번 확인하고 잘못된 스키마, 비정상 가격, 신뢰하지 않는
  출처와 다운그레이드를 거부합니다.
- 쿼터·토큰·예상 비용 집계는 15분마다 로컬에 저장하고 30일 동안 보관합니다.
- 알 수 없는 모델은 임의 단가에 연결하지 않습니다.

기록 창은 선택한 기간의 표본 수와 최근 시각을 표시하고 차트에 VoiceOver
요약을 제공합니다. **기록 삭제**는 저장된 건수를 다시 확인한 뒤 실행됩니다.

## 진단 정보

**설정 → 개인정보 → 제공자 진단**에서 복사하기 전에 보고서 내용을 확인할 수
있습니다. 토큰 합계와 모델 식별자는 기본적으로 제외되며 사용자가 직접 선택한
경우에만 포함되고, 포함 중에는 공유 전 확인 경고가 표시됩니다. 프롬프트,
응답, 인증정보, 쿠키와 파일 경로는 선택과
관계없이 항상 제외됩니다.
