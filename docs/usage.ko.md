# 사용량 표시 안내

## Codex 계정 토큰 사용량

Codex 계정 사용량은 실험적인 `codex app-server`의
`account/usage/read` 메서드에서 가져옵니다. 응답에는 날짜별 일일 버킷과
누적 합계가 포함되며, 일일 버킷은 해당 날짜가 끝난 뒤 도착할 수 있습니다.

팝오버에는 다음 값을 표시합니다.

- **최근 일일 사용량 (`yyyy-MM-dd`)**: 계정 서비스가 반환한 가장 최신
  날짜의 유효한 버킷 합계입니다. 로컬 날짜가 바뀌어도 계속 표시합니다.
- **이번 달**: 현재 로컬 달력의 이번 달에 속하는 유효한 반환 버킷의
  합계입니다.
- **누적**: 계정 서비스가 반환한 누적 합계입니다.

잘못된 값, 음수 및 미래 날짜 버킷은 제외합니다. 유효한 일일 버킷이 없으면
임의의 값을 만들지 않고 최근 일일 사용량을 사용할 수 없는 상태로 둡니다.
API 환산 비용은 집계 토큰을 이용한 거친 참고값이며 실제 구독 청구액이
아닙니다.

## Claude 메뉴바 쿼터

**설정 → 일반 → 메뉴바**에서 **선택한 제공자 잔여량**을 고르고 제공자를
**Claude Code**로 선택하면 **Claude 쿼터** 선택기가 나타납니다.

- **5시간**: `five-hour` 세션 창
- **일주일**: `seven-day` 계정 창
- **Fable**: 모델 범위의 `scoped-weekly-fable` 창

기존 동작을 유지하기 위해 기본값은 Fable이며 선택은 로컬에 저장됩니다.
현재 계정 응답에 선택한 창이 없으면 다른 쿼터로 바꾸어 표시하지 않고
Claude를 사용 불가 상태로 표시합니다.

## 비용 추정, 환율 및 기록

비용은 확인 가능한 계정 또는 로컬 토큰 합계를 공개 API 단가로 사용했을 때의
참고 추정액입니다. API 청구서나 Codex, ChatGPT, Claude 또는 Grok 구독
청구액이 아닙니다.

Codex 계정 활동은 정확한 API 비용 계산에 필요한 과거 모델, 입력·출력, 캐시 및
추론 토큰 구분 없이 총 토큰만 제공합니다. 일일·이번 달·누적 비용에는 검증된
`gpt-5-codex` 가격표와 캐시되지 않은 입력 80%·출력 20%를 가정한 버전 관리
참고 프로필을 사용합니다. 이 영역에서는 토큰 합계가 기준 데이터입니다.

- USD/KRW는 [Frankfurter](https://frankfurter.dev/)의 ECB 제공자를 통해
  한국 시간 기준 하루 한 번 확인합니다.
- 버전 관리되는 모델 가격표를 하루 한 번 확인하며 잘못된 스키마, 비정상 가격,
  신뢰하지 않는 출처 및 다운그레이드를 거부합니다.
- 쿼터, 토큰 및 예상 비용의 집계 샘플을 15분마다 로컬에 저장하고 30일 동안
  보관합니다.
- 알 수 없는 모델은 임의의 단가에 연결하지 않고 비용을 표시하지 않습니다.
