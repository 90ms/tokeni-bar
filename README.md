AI 코딩 에이전트의 **토큰·쿼터 상태**를 메뉴바에서 확인하고, 실제 토큰
사용량으로 두 세대, 열 종류의 픽셀 펫을 발견하고 키우는 macOS 앱입니다.

## 빠른 설치

```bash
brew install --formula 90ms/tap/tokeni-bar
tokeni-bar --install-app
tokeni-bar
```

| 요구 사항 | 내용 |
|---|---|
| 운영체제 | macOS 14 Sonoma 이상 |
| 빌드 도구 | 최신 Xcode Command Line Tools (`xcode-select --install`) |
| 에이전트 | Codex, Claude Code, GitHub Copilot, Cline, Antigravity, Grok Build 중 하나 이상 |

Formula는 사용자 Mac에서 앱을 빌드하고 ad-hoc 서명합니다. Apple Developer
ID와 전체 Xcode 앱은 필요하지 않습니다.

Homebrew가 신뢰를 요구하면 전체 tap 대신 Formula만 신뢰하세요.

```bash
brew trust --formula 90ms/tap/tokeni-bar
brew install --formula tokeni-bar
```

쿼터 비율은 항상 **남은 비율**이며 비용은 구독 청구액이 아닌 API 환산
참고값입니다.

## Tokeni 펫 성장 방식

### 1. 검증 토큰으로 레벨 100까지 성장합니다

검증된 누적 토큰 60만 개마다 성장 XP 1을 얻습니다. 60만 개 미만의 나머지는
날짜를 넘어 유지되며 활동 시간은 애니메이션만 바꾸고 XP를 만들지 않습니다.

```text
레벨 L 누적 XP = round(500 × ((L - 1) / 99) ^ 1.7)
```

레벨 100에는 누적 XP 500, 즉 총 3억 검증 토큰이 필요합니다. 초반은 빠르고
레벨이 높아질수록 느려집니다.

초기 최대 레벨은 100입니다. 레벨 10과 25에서 사용자가 직접 진화하면 성장기와
성체 외형으로 바뀌며 XP는 소비되지 않습니다. 진화를 미뤄도 레벨은 계속
상승합니다. 함께 표시하는 펫과 XP를 받는 성장 대상을 따로 선택할 수 있습니다.
다만 성장 대상이 100레벨에 도달하면 100레벨 미만인 보유 펫 중 하나를 자동으로
골라 현재 펫과 성장 대상으로 함께 전환합니다.

레벨 30·40, 50부터 5레벨마다, 60부터 3레벨마다, 70부터 매 레벨에
별조각을 받습니다. 한 펫이 100레벨까지 받는 레벨 보상은 총 460개입니다.
모든 보유 펫이 100레벨이면 현재 성장 대상을 유지하고, 이후 검증된 토큰 10만
개마다 별조각 10개로 반복 환산됩니다. 다음 환산까지의 진행도는 펫별로 보존됩니다.

### 2. 알로 새로운 펫을 수집합니다

최초 실행 시 판매할 수 없는 스타터 알 하나를 받고 무료로 부화합니다. 이후
새 펫은 기존 펫을 완료 처리하거나 교체하지 않고 알 보관함과 상점에서 얻습니다.
이전 버전에서 활성 펫을 키우던 사용자는 마이그레이션 때 귀환 선물 알 하나를
추가로 받습니다.

| 알 | 해금·획득 | 구매 | 판매 |
|---|---|---:|---:|
| 스타터 알 | 최초 실행 1회 | 무료 | 불가 |
| 귀환 선물 알 | 기존 활성 펫 마이그레이션 1회 | 구매 불가 | 불가 |
| 수수께끼 알 | 최고 펫 레벨 5 | 별조각 90 | 30 |
| 별빛 알 | 매일 첫 성장 활동 또는 서로 다른 3종 발견 | 별조각 180 | 60 |
| 프리즘 알 | 도감 마일스톤 | 구매 불가 | 60 |

별빛 알은 미발견 종이 남아 있으면 그중 하나를 보장하고 프리즘 10%, 변이 2%의
확률을 적용합니다. 프리즘 알은 프리즘 변종을 보장합니다. 서로 다른 종 5개와
10개를 발견하면 별빛 알을, 종·변종 조합 5·10·20·30개를 발견하면 프리즘 알을
각각 한 번 받습니다.

업데이트 전에 획득한 미개봉 알은 당시의 1세대 종 풀을 유지합니다. 업데이트 후
획득한 알부터 두 세대 열 종이 같은 기본 확률로 포함되어, 저장된 시드의 결과가
콘텐츠 추가만으로 바뀌지 않습니다.

새 알을 열어도 현재 펫은 사라지지 않습니다. 부화한 펫은 보유 목록에 추가되며
한 번에 한 펫을 성장 대상으로 골라 언제든 전환할 수 있습니다. 비활성 펫은 새
주인에게 보내 별조각을 받을 수 있지만 레벨은 판매가를 높이지 않고 도감 기록도
사라지지 않습니다.

### 3. 펫 관리 화면에서 도감과 보유 펫을 관리합니다

상단의 `펫` 화면 하나에서 현재 펫, 성장 상태, 도감과 보유 목록을 함께 관리합니다.
도감은 종·변종·성장 폼과 희귀 변이의 발견 기록을 보여주며, 보유 목록은 부화한 개별
펫의 레벨, 이름, 성격, 추억과 전환·동행·판매 액션을 제공합니다. 보유 목록의
`펫별 보기` 메뉴에서 종을 선택하면 해당 종만 표시할 수 있습니다.

도감은 검색·세대 필터 대신 1세대와 2세대 섹션으로 모든 종을 나누어 보여줍니다.
카드를 선택하면 펫 상세와 발견한 성장 단계, 공통 행동, 변이 전용 행동을 애니메이션으로
미리 볼 수 있습니다.

### 4. 두 세대 열 종과 변종을 발견합니다

1세대는 ByteBot, CacheCat, StackFox, PromptPup, NullSlime이고, 2세대
`시그널 원정대`는 QueryOwl, PatchPanda, LoopHare, RelayRay, KernelCrab입니다.
업데이트 후 획득한 알에서는 열 종의 기본 확률이 같습니다.
미발견 종이 남은 동안 중복 부화 5회 뒤에는 다음 일반 부화를 미발견 종에서
고릅니다.

2세대는 가슴의 시그널 코어와 행동별 모드 전환으로 구분됩니다. 작업·경고·고유
행동에서 날개, 귀, 지느러미나 등껍질의 실루엣이 바뀝니다. 전투력 우위는 없으며
1세대의 검증된 다섯 혜택을 같은 수치로 나눠 가집니다. 2세대 3종 발견 시 홀로그램
스캔라인 장면 효과, 5종 모두 발견 시 미니 드론 사이드킥이 무료 해금됩니다.

| 변종 | 기본 확률 | 성능 |
|---|---:|---|
| 기본색 | 91% | 동일 |
| 프리즘 | 8% | 동일 |
| 변이 | 1% | 동일 |

기본색이 11회 연속 나오면 12번째 일반 부화는 프리즘입니다. 메인 도감은
`10종 × 기본색·프리즘·변이` 총 30개이고, 진화 외형은 각 조합의 성장 앨범에
기록됩니다.

일반 알은 1% 확률로 해당 종의 희귀 변이 외형을 부화합니다. 변이는 기본색과
애니메이션을 유지하되 모든 프레임에 굵은 종별 신체 특징을 합성한 고유 개체이며,
장착형 장식이 아니고 성능에도 영향을 주지 않습니다.
동일한 `종 + 외형`이 다시 나오면 새 개체 대신 기존 펫이 다음 레벨 요구 XP의
25%를 받습니다. 변이도 일반 외형과 함께 도감에 등록됩니다.

### 5. 레벨과 활동으로 보상을 얻습니다

| 펫 레벨 | 최초 달성 보상 |
|---:|---|
| 5 | 2배·30분 부스터 |
| 10 | 3배·20분 부스터 |
| 20 | 반딧불 오라 |
| 25 | 5배·10분 부스터와 궤도 오라 |

꾸미기에는 오라·배경·사이드킥과 함께 펫 위치에 의존하지 않는 프레임·장면 효과
슬롯이 있습니다. 별자리·픽셀 포털 프레임과 떠다니는 구름·홀로그램 스캔라인·
흩날리는 꽃잎을 전체 펫 캔버스에 장착할 수 있습니다. 이전 바디 컬러와 발판
소유권 및 선택 상태는 대응하는 새 꾸미기로 자동 이전됩니다.

매일 첫 성장 활동은 별조각 300개와 별빛 알 하나를 지급합니다. 주간 출석 3·5·7일에는
각각 별조각 100·200·300개를, 월간 출석 20일에는 500개를 추가로 지급합니다. 별조각은 자동
활동 출석, 첫 검증 성장, 주간·월간 활동, 종·변종 발견과 안정
버전마다 꾸미기 탭에서 직접 받는 업데이트 보상 300개로도 얻습니다. 알, 꾸미기와
부스터 구매에 함께 사용합니다. 실제
결제, 기간 한정 상점, 사용자 간 거래, 연속 접속 손실은 없습니다.

전체 규칙은 [Tokeni 펫 성장과 알 도감](docs/bytebot.ko.md), 확장·밸런스
기준은 [Tokeni 펫 시스템 정책](docs/companion-policy.ko.md)을 참고하세요.

## 메뉴바와 화면 위 펫

메뉴바는 모든 표시 모드에서 macOS에 맞는 단색 상태 아이콘을 사용합니다. 열 수
있는 알이 있거나 레벨 10·25 진화가 준비되면 아이콘에 빨간 뱃지가
표시됩니다.

메뉴바 팝오버는 헤더와 사용 기록·설정·종료 액션을 고정하고, 가운데 내용만
스크롤합니다. 펫 상태 카드를 가장 먼저 보여주고 그 아래에 사용량과 갱신 시각을
표시합니다. 보유 펫은 성장 가능한 펫과 만렙 펫을 배지·색상과 정렬로 구분합니다.
각 제공자 카드의 추가 쿼터·토큰·참고 비용·출처는
축소 모드에서도 **상세 보기**에서 펼칠 수 있습니다.

**설정 → Tokeni → 화면 위에 펫 표시**를 켜면 투명한 펫 패널을 다른 앱 위에
둘 수 있습니다.

- 작게·보통·크게 중 표시 크기를 선택합니다.
- 펫을 클릭하면 기존 토닥임 동작과 좌우 점프로 반응합니다.
- 펫을 드래그한 위치는 다음 실행을 위해 Mac에 저장됩니다.
- 실제 펫 밖의 투명한 영역은 아래 앱으로 클릭을 전달합니다.
- 위치 잠금은 실수로 움직이는 것을 막습니다.
- 클릭 통과는 펫 아래 앱으로 마우스 입력을 전달하며, 켜진 동안에는 토닥임과
  이동을 사용할 수 없습니다.
- 위치 초기화는 펫을 현재 화면의 오른쪽 위로 되돌립니다.
- 패널은 모든 데스크톱 Space와 지원되는 전체화면 앱에 함께 표시됩니다.

날짜가 확인되는 로컬 기록만 오늘 합계에 넣고, 불완전하거나 시각이 없는 값은
0으로 추정하지 않습니다. 자세한 집계 기준은
[사용량 표시와 성장 집계](docs/usage.ko.md)를 참고하세요.

## 처음 사용하기

| 순서 | 할 일 |
|---:|---|
| 1 | 사용할 CLI를 터미널에서 한 번 실행하고 로그인 |
| 2 | Tokeni Bar를 실행하고 메뉴바의 상태 아이콘 열기 |
| 3 | **설정 → 일반**에서 제공자와 메뉴바 표시 방식 선택 |
| 4 | 계정 쿼터가 필요하면 **제공자 → 연결**을 선택합니다. 앱은 각 CLI의 기존 로그인 세션을 사용합니다 |
| 5 | 에이전트를 사용하면 첫 성장 활동이 자동 출석되고, 펫 성장·별조각 꾸미기를 확인한 뒤 필요하면 화면 위 펫 활성화 |

| 작업 | 명령 또는 위치 |
|---|---|
| 앱에서 업데이트 | **설정 → 일반 → 앱 업데이트 → 설치 후 재실행** |
| 터미널 업데이트 | `brew update && brew upgrade --formula 90ms/tap/tokeni-bar` |
| 앱 링크 갱신 | `tokeni-bar --install-app` |
| 앱만 제거 | `tokeni-bar --uninstall-app` |
| Formula 제거 | `brew uninstall --formula tokeni-bar` |

앱은 6시간마다 새 안정 버전을 확인하지만, 사용자가 버튼을 누르기 전에는 설치를
시작하지 않습니다. 설치 형태별 자세한 내용은
[Homebrew 설치 안내](docs/HOMEBREW.ko.md)를 참고하세요.

GitHub ZIP은 Apple Developer ID나 공증 없이 ad-hoc 서명된 빌드로 게시됩니다.
직접 설치하려면
[최신 릴리스](https://github.com/90ms/tokeni-bar/releases/latest)를 이용할 수
있습니다. 첫 실행이 차단되면 **시스템 설정 → 개인정보 보호 및 보안**에서
허용하세요.

직접 받은 릴리스 ZIP의 빌드 출처와 체크섬은 다음과 같이 확인할 수 있습니다.

```bash
gh attestation verify TokeniBar-<version>.zip --repo 90ms/tokeni-bar
shasum -a 256 -c TokeniBar-<version>.zip.sha256
```

## 개인정보 보호

| 저장하는 정보 | 저장하지 않는 정보 |
|---|---|
| 집계 쿼터·토큰·예상 비용 | 프롬프트와 모델 응답 |
| 펫 UUID·레벨/XP·종·외형·폼·성장 대상·알 보관함·보유 목록·이름·성격·추억·도감·보장 | 액세스 토큰·리프레시 토큰·쿠키 |
| 별조각·출석 날짜·알 거래 ID·구매한 꾸미기·부스터·지급 완료 식별자 | 계정 비밀정보와 서버 텔레메트리 |
| 화면 위 펫의 표시 설정과 마지막 위치 | 화면 캡처와 입력 내용 |
| 진행 상태 확인용 로컬 정보 | 원격 게임 계정과 분석 텔레메트리 |

사용 기록은 Mac에 30일 동안 보관합니다. 손상된 진행 데이터는 보관된 로컬
복구본으로 자동 복구를 시도합니다. 제공자 진단을 복사할 때 토큰 합계와 모델
식별자는 기본적으로 빠지며, 프롬프트·응답·인증정보·쿠키·파일 경로는 항상
제외됩니다. Claude와 Codex 계정 쿼터는 각 CLI의 비대화형 명령으로 확인하며,
앱이 CLI 인증정보를 읽거나 저장하지 않습니다. 분석 도구나 원격 게임 서버는
사용하지 않습니다.

## 문제 해결

| 증상 | 확인할 내용 |
|---|---|
| 앱 창이 보이지 않음 | Dock이 아닌 메뉴바 오른쪽의 Tokeni Bar 앱 아이콘 확인 |
| 화면 위 펫을 움직일 수 없음 | **설정 → Tokeni**에서 위치 잠금과 클릭 통과 끄기 |
| 화면 위 펫을 찾을 수 없음 | **설정 → Tokeni → 펫 위치 초기화** 선택 |
| 제공자가 사용 불가 | 해당 CLI의 설치·로그인 확인 후 한 번 실행 |
| Claude 또는 Codex 연결 실패 | 해당 CLI를 터미널에서 한 번 실행해 로그인한 뒤 **설정 → 일반 → 제공자**에서 연결 상태를 확인. Claude는 `claude auth status`, Codex는 기존 CLI 세션으로 인증 상태를 확인하며 Tokeni Bar가 로그인창을 열거나 인증정보를 읽지 않음 |
| Homebrew 신뢰 오류 | `brew trust --formula 90ms/tap/tokeni-bar` 실행 |
| Formula와 Cask 중 선택하라는 업데이트 오류 | `brew upgrade --formula 90ms/tap/tokeni-bar` 실행 후 `tokeni-bar --install-app`. 앱 내 업데이트는 0.25.2부터 Formula를 자동 지정 |
| 앱 내 Homebrew 업데이트에서 `$HOME` 오류 | 최신 버전으로 업데이트한 뒤 다시 시도. 이전 버전은 터미널에서 `brew upgrade --formula 90ms/tap/tokeni-bar && tokeni-bar --install-app` 실행 |
| 펫 진행을 읽지 못함 | 앱을 다시 실행해 로컬 자동 복구를 시도하고, 계속되면 진단 정보 확인 |
| 부스터를 사용할 수 없음 | 보유 수량 또는 구매할 별조각이 충분한지 확인. 같은 배율은 시간을 연장하고 다른 배율은 기존 남은 시간을 버리고 교체 |
| 메모리 사용량이 일시적으로 큼 | 대형 제공자 로그 갱신이나 새 펫 스프라이트 첫 표시 직후인지 확인. 한 번의 로그 스캔은 128MiB에서 중단되며, 사용하지 않는 화면 위 펫을 끌 수 있음. 지속적으로 증가하면 앱을 다시 실행한 뒤 진단 정보와 재현 절차를 함께 보고 |
