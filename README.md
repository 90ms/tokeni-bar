AI 코딩 에이전트의 **토큰·쿼터 상태**를 메뉴바에서 확인하고, 실제 토큰
사용량으로 다섯 종류의 픽셀 펫을 발견하고 키우는 macOS 앱입니다.

## 빠른 설치

```bash
brew install --formula 90ms/tap/tokeni-bar
tokeni-bar --install-app
tokeni-bar
```

| 요구 사항 | 내용 |
|---|---|
| 운영체제 | macOS 14 Sonoma 이상 |
| 빌드 도구 | 최신 Xcode Command Line Tools (`xcode-select --install`) |
| 에이전트 | Codex, Claude Code, Grok, Gemini CLI, OpenCode 중 하나 이상 |

Formula는 사용자 Mac에서 앱을 빌드하고 ad-hoc 서명합니다. Apple Developer
ID와 전체 Xcode 앱은 필요하지 않습니다.

Homebrew가 신뢰를 요구하면 전체 tap 대신 Formula만 신뢰하세요.

```bash
brew trust --formula 90ms/tap/tokeni-bar
brew install --formula tokeni-bar
```

## 무엇을 볼 수 있나요?

| 영역 | 제공하는 정보 |
|---|---|
| 메뉴바 | 단색 상태 아이콘, 가장 낮은 쿼터, 선택 제공자, 월 예상 비용 또는 펫 상태와 성장 준비 뱃지 |
| 사용량 | 제공자별 남은 쿼터, 초기화 시각, 토큰과 참고 비용 |
| 기록 | 최근 24시간·7일·30일의 로컬 집계 |
| 알림 | 잔여량, 쿼터 갱신, 월 예산, 연결 실패와 조용한 시간·중복 묶음 |
| Tokeni 펫 | 성장 단계, 종류, 시각 변형, 이름·성격·친밀도·추억, 행동과 선택형 화면 오버레이 |
| 도감·보상 | 핵심 발견 10개와 성장 앨범, 자동 활동 출석, 친밀도 보상, 에너지 부스터, 애니메이션 별조각 꾸미기와 가장 가까운 보장 |

확인할 수 없는 값은 추정하지 않고 **사용 불가** 또는 **오래됨**으로 표시합니다.
쿼터 비율은 항상 **남은 비율**이며 비용은 구독 청구액이 아닌 API 환산
참고값입니다.

## Tokeni 펫 성장 방식

### 1. 토큰이 성장 에너지로 바뀝니다

오늘 확인된 토큰 합계를 `T`라고 할 때:

```text
성장 에너지 = floor(T / 50,000)
```

| 오늘 사용한 토큰 | 오늘 성장 에너지 |
|---:|---:|
| 50,000 | 1 |
| 1,000,000 | 20 |
| 10,000,000 | 200 |
| 100,000,000 | 2,000 |
| 300,000,000 | 6,000 |

항상 검증된 토큰 5만 개당 에너지 1을 얻습니다. 5만 개 미만의 남은 토큰과
사용하지 않은 행동 에너지는 날짜가 바뀌어도 전부 유지됩니다. 검증 관측으로
새로 쌓이는 일반 행동 에너지는 비정상 데이터로부터 진행을 보호하기 위한 안전
상한 100,000까지만 보유하며, 같은 누적값은 여러 번 새로고침해도 한 번만
반영됩니다.

펫 도감의 **행동 에너지**에서는 오늘 성장에 실제로 반영된 토큰을 제공자별로
나누어 보여주고, 그 합계와 오늘 에너지 목표 및 다음 에너지 1에 필요한 추가
토큰을 함께 표시합니다. 일일 합계를 제공하지 않는 CLI는 Tokeni Bar가 확인한
세션·누적 증가분만 표시하며, 아직 기준선을 확인하지 못한 제공자는
**확인 대기**로 구분합니다.

Codex 계정 일일 버킷은 같은 계정의 여러 PC 사용량을 합산하지만 당일에는 아직
제공되지 않을 수 있습니다. Tokeni Bar는 최대 3일 안에 도착한 최신 확정 버킷을
원래 사용 날짜의 성장량으로 계산하고, 확인된 날의 행동 에너지에 정산합니다.
도감에는 사용 날짜와 **오늘 정산** 또는 **오늘 집계 대기** 상태가 표시됩니다.

### 2. 네 단계로 진화합니다

| 행동 | 소비 에너지 | 결과 |
|---|---:|---|
| 알 부화 | 500 | 펫 종류와 기본색·프리즘 변형을 공개하고 유년기로 이동 |
| 성장기 진화 | 800 | 같은 변형을 유지하며 성장기로 이동 |
| 성체 진화 | 1,400 | 같은 변형을 유지하며 성체로 이동 |
| 성체 여정 마치고 새로 부화하기 | 800 | 성체를 기록하고 새 펫을 즉시 부화 |
| 성체 전 새 알 받기 | 300 | 수수께끼 알로 초기화 |

에너지가 충분해도 자동으로 부화하거나 진화하지 않습니다. 사용자가 버튼을
직접 눌러야 다음 단계로 이동합니다. 성체 이후 얻는 에너지는 행동 잔액과 함께
친밀도에도 기록됩니다. 진화할 때는 이전 모습이 빛 속으로 들어간 뒤 새 단계가
나타나며, 동작 줄이기나 저전력 모드에서는 짧게 전환됩니다.

작업 중·최근 활동 뒤의 짧은 대기·쿼터 부족·토닥하기·장시간 비활동은 펫의
동작을 바꿉니다. 검증된 토큰이 성장 에너지로 반영되면 짧게 반짝이며, `idle`
상태에서는 가끔 작게 움직입니다. 이런 연출은 성장 에너지를 추가하지 않습니다.

알은 모든 펫이 공유하는 수수께끼 모습입니다. 부화할 때 ByteBot, CacheCat,
StackFox, PromptPup, NullSlime 중 하나가 각각 20% 확률로 공개됩니다. 아직
발견하지 못한 펫이 있다면 중복 부화 5회 뒤 다음 알은 미발견 종류를 보장합니다.

### 3. 기본색과 프리즘 변형을 수집합니다

새 펫의 변형은 부화할 때 한 번 결정되며 진화 중 바뀌지 않습니다.

| 변형 | 부화 확률 | 규칙 |
|---|---:|---|
| 기본색 | 92% | 각 종의 대표 외형 |
| 프리즘 | 8% | 능력치 차이가 없는 특별 시각 변형 |

기본색이 11번 연속 나오면 12번째 부화는 프리즘입니다. 이 보장은 종 보장과
동시에 적용될 수 있으며 도감은 둘 중 더 가까운 보장을 먼저 안내합니다.
기존 희귀·영웅 외형은 레거시 바디 컬러 꾸미기로, 전설 외형은 프리즘으로
대응할 수 있습니다. 이 이름의 `레거시`는 현재 제공하는 바디 컬러 자산을
뜻하며, 별도의 환급이나 자산 이전 기능은 없습니다.

### 4. 도감, 개체 기록과 새 알

| 선택 | 결과 | 유지되는 것 |
|---|---|---|
| 성체와 계속 지내기 | 추가 에너지가 친밀도로 누적 | 현재 외형과 모든 기록 |
| 성체 여정 마치기 | 에너지 800을 쓰고 기록 후 새 펫을 즉시 부화 | 도감과 변형·종 보장 |
| 성체 전 이별하기 | 에너지 300을 쓰고 새 알 시작 | 도감과 기존 보장 |

1세대 핵심 도감은 5종 × 기본색·프리즘으로 총 10개 발견입니다. 실제로 만난
유년기·성장기·성체 모습은 각 발견의 **성장 앨범**에 별도로 남습니다.
현재 펫에는 최대 24자의 이름을 붙일 수 있고, 표현 전용 성격과 5단계 친밀도,
부화·진화·첫 토닥임·친밀도 상승·여정 완료 추억이 기록됩니다. 추억에는
작업 내용이나 사용량 숫자가 들어가지 않습니다.

친밀도 레벨 2·3·4·5를 세대별로 처음 달성하면 각각 2배 부스터, 3배 부스터,
반딧불 오라, 5배 부스터와 궤도 오라를 얻습니다. 부스터로 늘어난 행동
에너지는 친밀도를 추가로 올리지 않으므로 친밀도가 자기 자신을 가속하지
않습니다.

성장을 마친 펫은 **완료한 펫**에서 다시 꺼내 대표 펫으로 표시하거나 보관할
수 있습니다. 이름·성격·친밀도·추억은 개체마다 유지되지만 성장량, 비용,
확률이나 보상을 바꾸는 능력치는 없습니다.

### 5. 활동과 도감 성취로 별조각을 얻습니다

성장 에너지는 계속 검증된 토큰 사용량으로만 얻습니다. 출석과 도감 활동은
별도 재화인 **별조각**을 지급합니다.

| 획득 조건 | 별조각 |
|---|---:|
| 그날 첫 검증 성장 시 자동 활동 출석 | 10 |
| 그날 첫 검증 성장 | 5 |
| 주간 누적 3일 / 5일 / 7일 | 10 / 20 / 30 |
| 월간 누적 20일 | 50 |
| 새로운 펫 최초 발견 | 20 |
| 프리즘 최초 발견 | 50 |
| 성체 여정 완료 | 25 |
| 변형 도감 5개 / 10개 해금 | 20 / 100 |
| 새 안정 버전 첫 실행 | 20 |

별도의 출석 버튼은 없습니다. 그날 처음 검증된 성장 관측이 반영되면 활동
출석도 자동 처리됩니다. 하루를 놓쳐도 그 주와 달의 누적 횟수는 유지됩니다. 같은 날짜의 중복
수령은 차단하며, 시스템 날짜가 마지막 출석일보다 과거이면 날짜가 정상화될
때까지 새 출석을 지급하지 않습니다.

별조각은 펫 도감의 **별조각 꾸미기**에서 다음 영구 꾸미기를 구매하고
착용하는 데 사용합니다.

| 슬롯 | 꾸미기 | 별조각 |
|---|---|---:|
| 오라 | 반짝임 / 픽셀 하트 / 반딧불 / 궤도 / 밤하늘 링 | 60 / 80 / 130 / 180 / 200 |
| 배경 | 터미널 나이트 / 구름 정원 / 노을 그리드 / 픽셀 숲 | 160 / 220 / 240 / 260 |
| 바디 컬러 | 레거시 블루 / 레거시 바이올렛 | 90 / 110 |

구매 전 현재 조합과 구매 후 모습을 나란히 확인할 수 있습니다. 꾸미기는 메뉴
팝오버, 펫 관리 화면과 화면 위 펫에 함께 적용되며 슬롯·보유 상태 필터로
찾을 수 있습니다. 슬롯별 하나씩 동시에 착용할 수 있고 완료한 동료의 상세
화면에서는 전체 추억과 개체 기록을 확인할 수 있습니다. 꾸미기 크기는 설정의 작게·보통·크게
펫 크기에 맞춰 조정됩니다. 각 아이템은 고유 애니메이션을 가지며 강도는
끔·잔잔하게·풍부하게 중 선택할 수 있습니다. 밝은 배경에서는 오라 대비를
자동 보정합니다. 성장 에너지, 변형, 보장 확률이나 보상에는 영향을 주지
않습니다. 펫의 재미는 수치 우위가 아니라 수집, 개체 기록, 애니메이션과
꾸미기 조합에 집중합니다. 펫 종류와 성장 단계마다 위치가 달라지는 머리
장식 슬롯은 제공하지 않습니다.

### 6. 시간제 행동 에너지 부스터

별조각으로 소비형 부스터를 구매하거나 친밀도 단계 보상으로 얻을 수 있습니다.

| 부스터 | 지속 시간 | 별조각 |
|---|---:|---:|
| 2배 | 30분 | 80 |
| 3배 | 20분 | 150 |
| 5배 | 10분 | 280 |

부스터는 활성 중 새로 확인되어 지급되는 **기본 행동 에너지**에만 적용합니다.
동시에 하나만 활성화할 수 있으며 활성 시각과 종료 시각을 로컬에 저장합니다.
앱을 다시 실행해도 종료 시각은 늘어나지 않고, 만료 뒤 배율은 자동으로 1배가
됩니다. 다른 시스템의 추가 에너지나 친밀도에는 배율을 다시 적용하지 않습니다.

메뉴의 격자 버튼 또는
**설정 → Tokeni → 펫 도감 열기**에서 모든 기록을 확인할 수 있습니다.
전체 규칙은 [Tokeni 펫 성장과 도감](docs/bytebot.ko.md), 확장·밸런스 기준은
[Tokeni 펫 시스템 정책](docs/companion-policy.ko.md)에 정리되어 있습니다.

## 메뉴바와 화면 위 펫

메뉴바는 모든 표시 모드에서 macOS에 맞는 단색 상태 아이콘을 사용합니다. 알을
부화하거나 유년기·성장기 펫을 다음 단계로 진화할 에너지가 모이면 아이콘에 빨간
뱃지가 표시됩니다. 성체의 여정 완료 준비는 이 뱃지에 포함하지 않습니다.

메뉴바 팝오버는 헤더와 사용 기록·설정·종료 액션을 고정하고, 가운데 내용만
스크롤합니다. 사용량과 갱신 시각을 먼저 보여주고 펫 카드는 항상 표시합니다.
각 제공자 카드의 추가 쿼터·토큰·참고 비용·출처는
축소 모드에서도 **상세 보기**에서 펼칠 수 있습니다.

**설정 → Tokeni → 화면 위에 펫 표시**를 켜면 투명한 펫 패널을 다른 앱 위에
둘 수 있습니다.

- 작게·보통·크게 중 표시 크기를 선택합니다.
- 펫을 클릭하면 기존 토닥임 동작과 좌우 점프로 반응합니다.
- 펫을 드래그한 위치는 다음 실행을 위해 Mac에 저장됩니다.
- 위치 잠금은 실수로 움직이는 것을 막습니다.
- 클릭 통과는 펫 아래 앱으로 마우스 입력을 전달하며, 켜진 동안에는 토닥임과
  이동을 사용할 수 없습니다.
- 위치 초기화는 펫을 현재 화면의 오른쪽 위로 되돌립니다.
- 패널은 모든 데스크톱 Space와 지원되는 전체화면 앱에 함께 표시됩니다.

## 제공자 지원

| 제공자 | 계정 쿼터 | 토큰·비용 표시 | 펫 성장 기준 |
|---|---|---|---|
| Codex | 주간·모델별 한도와 충전권 | 최근 확정 일일·이번 달·누적 토큰, 집계 상태, 참고 비용 | 최대 3일 안에 도착한 확정 일일 합계 또는 세션 증가분 |
| Claude Code | 5시간·주간·모델별 한도 | 로컬 일일 토큰, 캐시 반영 참고 비용 | 확인된 일일 합계 |
| Grok | 미지원 | 현재 로컬 세션 컨텍스트 | 첫 관측 이후 세션 증가분 |
| Gemini CLI | 미지원 | 최근 로컬 세션 토큰 | 첫 관측 이후 세션 증가분 |
| OpenCode | 미지원 | 로컬 누적 토큰과 기록 비용 | 첫 관측 이후 누적 증가분 |

세션·누적 카운터는 첫 값을 기준선으로 삼아 과거 사용량이 새 성장량으로
지급되는 것을 막습니다. 자세한 집계 기준은
[사용량 표시와 성장 집계](docs/usage.ko.md)를 참고하세요.

## 처음 사용하기

| 순서 | 할 일 |
|---:|---|
| 1 | 사용할 CLI를 터미널에서 한 번 실행하고 로그인 |
| 2 | Tokeni Bar를 실행하고 메뉴바의 상태 아이콘 열기 |
| 3 | **설정 → 일반**에서 제공자와 메뉴바 표시 방식 선택 |
| 4 | Claude 계정 쿼터가 필요하면 **제공자 → 연결** 선택 |
| 5 | 에이전트를 사용하면 첫 성장 활동이 자동 출석되고, 펫 성장·별조각 꾸미기를 확인한 뒤 필요하면 화면 위 펫 활성화 |

## 업데이트와 제거

| 작업 | 명령 또는 위치 |
|---|---|
| 앱에서 업데이트 | **설정 → 일반 → 앱 업데이트 → 설치 후 재실행** |
| 터미널 업데이트 | `brew update && brew upgrade --formula 90ms/tap/tokeni-bar` |
| 앱 링크 갱신 | `tokeni-bar --install-app` |
| 앱만 제거 | `tokeni-bar --uninstall-app` |
| Formula 제거 | `brew uninstall --formula tokeni-bar` |

앱은 6시간마다 새 안정 버전을 확인하지만, 사용자가 버튼을 누르기 전에는 설치를
시작하지 않습니다. 설치 형태별 자세한 내용은
[Homebrew 설치 안내](docs/HOMEBREW.ko.md)를 참고하세요.

GitHub ZIP은 Apple Developer ID나 공증 없이 ad-hoc 서명된 빌드로 게시됩니다.
직접 설치하려면
[최신 릴리스](https://github.com/90ms/tokeni-bar/releases/latest)를 이용할 수
있습니다. 첫 실행이 차단되면 **시스템 설정 → 개인정보 보호 및 보안**에서
허용하세요.

직접 받은 릴리스 ZIP의 빌드 출처와 체크섬은 다음과 같이 확인할 수 있습니다.

```bash
gh attestation verify TokeniBar-<version>.zip --repo 90ms/tokeni-bar
shasum -a 256 -c TokeniBar-<version>.zip.sha256
```

## 개인정보 보호

| 저장하는 정보 | 저장하지 않는 정보 |
|---|---|
| 집계 쿼터·토큰·예상 비용 | 프롬프트와 모델 응답 |
| 펫 종류·단계·변형·이름·성격·친밀도·추억·도감·보장 | 액세스 토큰·리프레시 토큰·쿠키 |
| 별조각·출석 날짜·구매한 꾸미기·부스터·지급 완료 식별자 | 계정 비밀정보와 서버 텔레메트리 |
| 화면 위 펫의 표시 설정과 마지막 위치 | 화면 캡처와 입력 내용 |
| 진행 상태 확인용 로컬 정보 | 원격 게임 계정과 분석 텔레메트리 |

사용 기록은 Mac에 30일 동안 보관합니다. 손상된 진행 데이터는 보관된 로컬
복구본으로 자동 복구를 시도합니다. 제공자 진단을 복사할 때 토큰 합계와 모델
식별자는 기본적으로 빠지며, 프롬프트·응답·인증정보·쿠키·파일 경로는 항상
제외됩니다. 분석 도구나 원격 게임 서버는 사용하지 않습니다.

## 문제 해결

| 증상 | 확인할 내용 |
|---|---|
| 앱 창이 보이지 않음 | Dock이 아닌 메뉴바 오른쪽의 Tokeni Bar 앱 아이콘 확인 |
| 화면 위 펫을 움직일 수 없음 | **설정 → Tokeni**에서 위치 잠금과 클릭 통과 끄기 |
| 화면 위 펫을 찾을 수 없음 | **설정 → Tokeni → 펫 위치 초기화** 선택 |
| 제공자가 사용 불가 | 해당 CLI의 설치·로그인 확인 후 한 번 실행 |
| 잠금 해제 때 Claude 암호창이 반복됨 | 최신 버전으로 업데이트하고 **설정 → 일반 → 제공자**에서 한 번 연결. 백그라운드 조회는 인증창을 열지 않음 |
| Homebrew 신뢰 오류 | `brew trust --formula 90ms/tap/tokeni-bar` 실행 |
| 펫 진행을 읽지 못함 | 앱을 다시 실행해 로컬 자동 복구를 시도하고, 계속되면 진단 정보 확인 |
| 부스터를 사용할 수 없음 | 이미 활성화된 부스터가 있는지, 보유 수량 또는 구매할 별조각이 충분한지 확인 |
